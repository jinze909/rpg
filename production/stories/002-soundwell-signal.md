# 002 · 亲手试出借声兽的规律

状态：已实现并通过 Unity Play Mode 自动化验收。真人试玩待做。

## 玩家得到什么

在入口安全区亲手摇铃、用湿布止声，看见借声兽按规则改变目标，并能回撤、重复试验。此卡只证明交互与反馈链可执行，不裁决整场救援是否好玩，也不决定移动／固定阵位胜负。

设计依据：[声井首个可玩样本](../../docs/gameplay/FIRST_PLAYABLE.md)与[玩法基线](../../docs/gameplay/BASELINE.md)。

## 范围

- 一张 PLACEHOLDER 场景，入口安全试验区；一名可控占位角色、一只兽、铜铃与湿布。
- 保存的真实玩家／场景配置、2D 输入与交互接线是必要前提；缺少时先补这条最短接线，不另造 RPG 状态系统。
- 声源只有清响／止声等明确状态，以命名位置处理；不做真实声波、完整潜行、战斗、第二伤员或整条 ST-04。
- 使用 ORK／Makinom 的单一权威事实，Unity 负责 2D 移动和可见反馈。具体 API 不可用时记录真实错误，不能用 Console 布尔演示替代玩家路径。

## 操作

在 Unity 进入 Bootstrap 的 Play Mode，按 **F2** 打开试验场景。**WASD／方向键**移动，靠近铃后按 **E** 摇铃，按 **Q** 包铃或解开湿布。回到入口标记后按 **R** 重试。占位界面使用英语。
