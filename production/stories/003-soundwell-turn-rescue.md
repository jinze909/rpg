# 003 · 三人短回合声井救援

状态：**003 移动版代表环与固定阵位救援闭环均已工程验收**。两条救援路线、真实 ORK 三人回合、受阻挡且可取消的战中走位、站位改变开闸分工、战败重试，以及固定阵位下的三动作战斗、物理护送与 ORK 救援奖励均有回归。最新 dev SHA `80174a557cd27b0ba2570db0bfdab1e7a8037e13` 的 [Run 44141955284](https://github.com/jinze909/rpg/actions/runs/44141955284) 通过 111/111、零跳过、独立 Batch 与 `passed-clean-candidate`。公平策略体验、后续成长/持久化与主观乐趣仍未验收。

## 玩家得到什么

在现有声井场地指挥三名功能样本，观察威胁，以引兽或正面牵制救出测路人，并获得人物回应。设计范围与对照条件见[首样本](../../docs/gameplay/FIRST_PLAYABLE.md)。

## 已有实现与证据边界

- 引兽路径：搬铃/侧铃引兽、开闸、询问测路人、加固踏板、实际护送至安全点；NPC拆错路标、玩家可选择告知车的位置、NPC取地图并重标路线。`SoundwellSmokeHost` 通过输入适配层注入/UGUI调用与独立状态/位置断言覆盖此链。
