# 《归来》战斗深度与目标化遭遇设计（补充融合版）

本文档作为 [玩法基线](BASELINE.md) 与 [首段可玩切片](FIRST_PLAYABLE.md) 战斗部分的增量融合规格，不改变既有核心红线（手工区域探索 + 精短回合制遭遇 + 非暴力/目标导向破局 + **ORK 3 为唯一 HP/伤害/轮次/胜负权威**），旨在解决原型阶段“纯数值互砍、三角色同质、战中微调走格负担大于决策价值、缺乏明牌博弈”的体验问题。

## 1. 四项战斗核心原则

1. **明牌威胁与破锁打断（Lock-Break Telegraph）**：
   - 敌人每回合开始前直接明牌下一拍的**行动目标、威胁类型与 1–2 把可破解锁**（如 `ShieldParry`、`BladeRepel`、`WetClothMuffle`、`DecoyBellRing`）。
   - 每破除 1 把锁即削弱威胁（如 50% 减威），**全破则直接打断敌方蓄力并使其进入 `Broken`（失衡破防）状态**。
   - **真实性红线**：任何界面提示、按钮高亮或破锁反馈必须绑定 ORK/宿主实际声明的敌方意图与实际结算，严禁靠猜测翻转状态误导玩家。
2. **共享稳势点（Shared Momentum，0–3 点）**：
   - 稳健应对（如架挡、稳阵、成功化解威胁）积累 `+1` 稳势点（上限 3）。
   - 消耗 `1` 点稳势点可触发强力破锁打断、援护或趁 `Broken` 窗口打出强化协同，让玩家在“立刻交资源破锁”与“攒气留给下一拍爆发/撤离”之间做清晰权衡。
3. **默认固定阵位 + 三角色差异化职责**：
   - 探索与空间感交由 4 倍大地图（`RpgLargeMapLayouts` + `RpgLargeMapExplorerController`）承担；进入战斗默认采用**固定阵位**，去除琐碎的四向半步微调操作。
   - 多人小队（如钟岭声井 3 人）中，3 个槽位分别承担**前排护阵（Vanguard）**、**声学破局（Acoustic Breaker）**、**控场支援（Field Support）**，每次轮到队员都有两个随当前威胁动态变化的真实抉择。
4. **目标导向胜负，而非只把血条砍零**：
   - 每场核心战都有与剧情严丝合缝的专属胜利钩子，HP 与败北仍完全由 ORK 3 权威判定。

## 2. S00 白水渡守桥战：1 人独守 · 护缆撑过三声钟响

- **剧情对齐**：按白水渡序章原文（「沈砾攥紧缆索，你转身守桥」），S00 参战操作位应为**主角 1 人独守**，不再硬套 3 名无名守桥克隆人；沈砾作为桥头缆索进度方在旁配合。
- **核心目标**：保住沈砾完成 **3 拍断缆（`0/3 -> 3/3` 三声钟响）**，撑满三声钟即触发断桥收束，而非“把持矛小队全灭”。
- **敌方两类明牌威胁与反制**：
  - **长矛重刺（锁定主角，`ShieldParry` 锁）**：推荐架盾硬顶（路由至 ORK 防御）-> 化解重创、`+1` 稳势、沈砾断缆进度 `+1`。
  - **工兵扑缆（锁定沈砾缆索，`BladeRepel` 锁）**：必须挥刀逼退（路由至 ORK 攻击）打断扑缆 -> 守住缆索、沈砾断缆进度 `+1`；若未打断则缆索受阻、本拍无法推进钟响。
- **节奏目标**：2–3 个干脆利落的回合完成序章首战，立刻衔接第三声钟响断桥。

## 3. 钟岭声井·借声兽：3 人声学破锁 · 集火或零杀伤脱身

- **核心机制**：借声兽每轮威胁带有 **2 层听觉锁**（`WetClothMuffle` + `DecoyBellRing`）；未破锁时硬攻收益低且易引来声波反击。
- **3 人连携破局**：
  1. 控场支援甩出**湿布消音**（破除第 1 把听觉锁，降噪归零）；
  2. 声学破局（沈砾）**敲响铜铃**（破除第 2 把听觉锁，借声兽撞墙失衡进入 `Broken`）；
  3. 破防后玩家面临真正的二选一：**全员趁破防由 ORK 结算重击**，或**趁失衡直接拉闸/护送受困者零杀伤脱身**。

## 4. 工程落地与权威边界

- `CombatLockBreakRules.cs` 仅负责**稳势点、敌方明牌锁条、S00 三声钟护缆进度与声井听觉破锁/脱身窗口**的纯规则状态机，**不持有任何独立 HP、伤害数值或败北判定**；所有战斗血量、回合推进与最终胜负仍严格委托给 ORK 3（`OrkPartyBridge`）。
- 后续场景接线任务将把 `WhitewaterDefenseEncounter.cs` 收束为单人独守并接入 `S00BridgeheadCableTracker`，同时把声井战斗接入 `SoundwellAcousticBreakTracker`。
