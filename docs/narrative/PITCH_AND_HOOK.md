# 《归来》卖点与开场 v0.2

“归来”为工作标题。本文为卖点与演出概念稿，商店页、预告片和场景均未制作，不能当作已实现玩法的宣传承诺。本文回答一个问题：玩家在商店页、预告片和前十五分钟里，凭什么决定玩下去。依据见 [NARRATIVE_GUIDE.md](NARRATIVE_GUIDE.md) 第四节。

## 一、一句话

**战死是一道公文。盖了章，人就不存在了。你回来，是要把他们一个个从死人名册上领回来。**

宣传语：**他们说你们死了。你回来点名。**

备选：战死的人，点名不会应。你回来，等他们应。

场景钩（预告片和开场用）：石头上写着你是怎么死的。写下它的人，现在请你吃饭。念到你的名字时，你可以应一声“在”。

## 二、钩与心

| | 内容 | 作用 |
| --- | --- | --- |
| 概念钩 | 战死是行政状态，救人是把人从名册上领回来 | 让人在商店页停下来 |
| 场景钩 | 你站在自己的纪念碑前，孩子们在台上演你的壮烈殉国 | 让人看完预告片 |
| 仪式钩 | 点名：被念到的名字有人应一声“在” | 预告片的转折，也是全作最后一幕 |
| 玩法钩 | 修理、航行、调查、交涉，每个选择都有人付代价 | 让人相信这是能玩的 |
| 心 | 你与沈砾：她不再是等你救的人；一群被登记为死亡的人怎样重新成为活人 | 让人玩到最后 |
| 桥 | S00 序幕：先让玩家认识沈砾，亲手体验被留下，再让玩家去救她 | 让钩和心接上 |

钩把人带进来，心把人留下。钩让人想去救人，心在共同脱困之后发现：她需要帮助，也有自己的计划和牵挂。宣传保留见面时的惊喜，但不靠“她根本不用救”否定中段真实营救。

## 三、商店页简介（约 150 字）

战争结束八年，仍有人被登记为“战死”，在海外的矿底下干活。你是其中一个。三个月前你逃了出来，留下一个替你挡下后果的朋友。你的名字刻在临潮港的纪念碑上，写着你是怎么壮烈死去的。你要渡海，把她带出来。可等你到了，事情和你想的不一样。

修理、航行、调查、交涉。每个选择，都有人为它付出代价。

## 四、30 到 45 秒预告片节拍

1. 黑屏，海风，钟声三下。
2. 石碑前，有人在念名字。一个，又一个，每念一个，沉默一拍。没有人答。
3. 念到一个名字。人群里，一个人开口：“在。”所有人回头。
4. 闪回：夜里的浮桥，缆在火光中崩开，一只手伸向你。
5. 赤盐矿的泵房，一只手拧阀；矿工们压低声音骂“税务官”。
6. 雾里，船头的人把一个名字叫进雾里。远处有人应：“在。”
7. 三张脸一闪而过：盖章的韩峤，举着丑杯子的祁雀，数着数字的陆钧。
8. 标题《归来》。宣传语：他们说你们死了。你回来点名。

镜头里出现的动作要能对应真实玩法：修、航行、查缆口、对名册、谈判、动手。

## 五、前十五分钟

只重点介绍三个名字：你、沈砾、韩峤；不把陌生词堆成考试。S00 的时长为场景稿目标，不是已测游戏时长，也不替代技术 P0。晏国、瑟兰、总帅部这些词都放到后面，开头只说“桥这边”和“桥那边”。

| 时间 | 内容 | 教玩家什么，埋下什么 |
| --- | --- | --- |
| 0 到 2 分钟 | 夜，浮桥，后卫阵地。军士点名，沈砾答“在，修着呢”，你自己选怎么答；她给扳手起名“税务官”，把另一把递给你 | 点名的规矩；修理与搬运；她的说话方式；工具外号，后来成为矿工暗号 |
| 2 到 5 分钟 | 她说战后想开一间接得起普通订单的工坊，问你要不要来 | 她的梦想，三种回答（答应、推脱、开玩笑）；玩家开始在意她 |
| 5 到 8 分钟 | 伤兵韩峤落水，你把他拖上最后一条船 | 救人；你和他的“互救” |
| 8 到 12 分钟 | 敌军压上。你守桥头，带最后一批掉队的人上桥，喊“谁带了多余的绳子” | 基础战斗与协作；这句话与纪念日台上的“桥在我在”形成反差 |
| 12 到 14 分钟 | 号钟敲三下，缆在火光里崩开，桥的另一端沉进水里。沈砾抓住你的手，被冲开 | 你亲历“被留下”；你从此听见钟声就数到三；你没看见是谁砍的 |
| 14 分钟以后 | 黑屏。十二年后，临潮港纪念日，碑前点名，念到你的名字 | 你可以应“在”；孩子在台上喊“桥在我在”，你和玩家都知道那一夜真正喊的是什么 |

## 六、每章结尾留给玩家的问题

| 章 | 结尾的问题 |
| --- | --- |
| S00 | 桥是谁断的？她与你怎样从被留下的人变成俘虏，十二年里发生了什么？ |
| M00 | 念到我的名字，我选择怎样回应。战报是谁写的？为什么说桥被烧了？ |
| M01 | 姜婶的钱怎么办？公开身份，值不值？ |
| M02 | 缆口证实人为切割，总帅令交给了谁执行？ |
| M03 | 陆钧为什么主动承认？他要我替他守什么？ |
| M04 | 离开她这三个月，赤盐究竟变成了什么样？ |
| M05 | 我逃走的那个月，到底发生了什么？ |
| M06 | 她为什么不肯直接走？泵一停会怎样？ |
| M07 | “明年谁给剩下的人付粮”，谁来答？ |
| M08 | 她早就知道缆是切的，我该不该生气？ |
| M09 | 两份名单，谁的承诺先算数？ |
| M10 | 韩峤那份战报，我拿它做什么？回澜出事了。 |
| M11 | 她来救我，接下来谁管谁？ |
| M12 | 渡口的真相，说，还是不说？ |
| M13 | 谁愿意跟我去？ |
| M14 | 三条路，哪一条才是回家？ |
| M15 | 石碑上，最后写什么？ |

写章节稿时，各章推进已有问题，允许相处章停下来回应人物；不为钩子强塞反转，也不在已经获得答案后假装玩家仍不知道。

## 七、紧迫感不靠倒计时

《博德之门3》的“脑袋里的寄生虫”让每个任务都有来由，也有它自己的缝隙：既然时间紧迫，为什么还能随便睡觉？

归来的紧迫感用已公布的事件承担。每个阶段都有一个角色说出口的、章节推进才会触发的事：监察船将到岛、鲁斯会在那之前拆散转运、会盟开幕、回澜关封航。关键危险由玩家确认的章节事件推进，闲逛不会暗中害死朋友。M04 已有出发前的安静一晚，途中也允许合理休息与地方活动；M08 是营救成功后的首次共同庆祝，意义来自真正兑现承诺。角色不一边允许自由探索，一边持续斥责玩家耽误救人。

## 八、四张海报画面

做出来才有“想玩”的冲动，要提早进美术需求：

1. 你的手按在刻着自己名字的石头上。
2. 火光里甩开的断缆。
3. 沈砾站在巨大的泵机前，拍着机壳。
4. 雾里一排船，钟楼上的钟在敲。

## 九、会让玩家放下手柄的地方，以及对策

| 风险 | 对策 |
| --- | --- |
| 开场太安静，只有纪念日小品 | 先玩 S00，再进 M00，小品因此有了反讽 |
| 名字和政治词太多 | 前十五分钟只出现三个名字，国名放到 M02 以后 |
| 宣传里提前泄露“她已经在组织修理班” | 预告片只展示“救她”，反转留给 M05 之后 |
| 中段救出沈砾之后动力不足 | M08 夜里的“她早就知道”、M09 的两份名单、M12 的真相选择，三个新问题接力 |
| 玩家不知道“领人”具体做什么 | 商店页和预告片出现修理、航行、调查缆口、谈判，开场先让玩家修理、搬运与协作，航行、调查和谈判按后续章节逐步引入，不承诺十分钟塞完全部系统 |
