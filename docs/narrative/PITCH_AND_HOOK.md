# 《归来》卖点与开场 v0.2

“归来”为工作标题。本文回答一个问题：玩家在商店页、预告片和前十五分钟里，凭什么决定玩下去。依据见 [NARRATIVE_GUIDE.md](NARRATIVE_GUIDE.md) 第四节。

## 一、一句话

**战死是一道公文。盖了章，人就不存在了。你回来，是要把他们一个个从死人名册上领回来。**

宣传语：**他们说你们死了。你回来点名。**

备选：战死的人，点名不会应。你回来，等他们应。

场景钩（预告片和开场用）：石头上写着你是怎么死的。写下它的人，现在请你吃饭。念到你的名字时，你可以应一声“在”。

## 二、钩与心

| | 内容 | 作用 |
| --- | --- | --- |
| 概念钩 | 战死是行政状态，救人是把人从名册上领回来 | 让人在商店页停下来 |
| 场景钩 | 你站在自己的纪念碑前，孩子们在台上演你的壮烈殉国 | 让人看完预告片 |
| 仪式钩 | 点名：被念到的名字有人应一声“在” | 预告片的转折，也是全作最后一幕 |
| 玩法钩 | 修理、航行、调查、交涉，每个选择都有人付代价 | 让人相信这是能玩的 |
| 心 | 你与沈砾：她不再是等你救的人；一群被登记为死亡的人怎样重新成为活人 | 让人玩到最后 |
| 桥 | P0 序章：先让玩家认识沈砾，亲手体验被留下，再让玩家去救她 | 让钩和心接上 |

钩把人带进来，心把人留下。钩说“救人”，心发现“她不需要被救”，这个反转不要提前泄露在宣传里。

## 三、商店页简介（约 150 字）

战争结束八年，仍有人被登记为“战死”，在海外的矿底下干活。你是其中一个。三个月前你逃了出来，留下一个替你挡下后果的朋友。你的名字刻在临潮港的纪念碑上，写着你是怎么壮烈死去的。你要渡海，把她带出来。可等你到了，事情和你想的不一样。

修理、航行、调查、交涉。每个选择，都有人为它付出代价。

## 四、30 到 45 秒预告片节拍

1. 黑屏，海风，钟声三下。
2. 石碑前，有人在念名字。每个名字念三遍，每遍之后沉默一拍。没有人答。
3. 念到一个名字。人群里，一个人开口：“在。”所有人回头。
4. 闪回：夜里的浮桥，缆在火光中崩开，一只手伸向你。
5. 盐矿深处，一只手在拧阀，镜头不给脸。
6. 雾里，船头的人把一个名字叫进雾里。远处有人应：“在。”
7. 三张脸一闪而过：盖章的韩峤，举着丑杯子的祁雀，数着数字的陆钧。
8. 标题《归来》。宣传语：他们说你们死了。你回来点名。

镜头里出现的动作要能对应真实玩法：修、航行、查缆口、对名册、谈判、动手。

## 五、前十五分钟

只出现三个名字：你、沈砾、韩峤。晏国、瑟兰、总帅部这些词都放到后面，开头只说“桥这边”和“桥那边”。

P0 的目标是十分钟左右，不超过十二分钟。第一分钟内必须有一次操作（点名应声）；不可操作的演出每段尽量不超过半分钟（我的建议值）；对话可以快进或跳过，重玩时可整段跳过。后面的 M00 再给五分钟左右。

| 时间 | 内容 | 教玩家什么，埋下什么 |
| --- | --- | --- |
| 0 到 1 分钟 | 夜，浮桥，后卫阵地。军士点名，沈砾答“在，修着呢”，你自己选怎么答；有人三遍没答，差点被划掉名字；她给扳手起名“税务官”，把另一把递给你 | 点名的规矩（三遍没人答，就划去）；修理与搬运；她的说话方式；工具外号，后来成为矿工暗号 |
| 1 到 3 分钟 | 她说战后想开一间接得起普通订单的工坊，问你要不要来 | 她的梦想，三种回答（答应、推脱、开玩笑）；玩家开始在意她 |
| 3 到 5 分钟 | 参军韩峤落水负伤，你把他拖上最后一条船 | 救人；你和他的“互救” |
| 5 到 8 分钟 | 敌军压上。你守桥头，带最后一批掉队的人上桥，喊“谁带了多余的绳子” | 基础战斗与协作；这句话与纪念日台上的“桥在我在”形成反差 |
| 8 到 10 分钟 | 号钟敲三下，缆在火光里崩开，桥的另一端沉进水里。沈砾抓住你的手，被冲开 | 你亲历“被留下”；你从此听见钟声就数到三；你没看见是谁砍的 |
| 10 分钟以后 | 黑屏。十二年后，临潮港纪念日，碑前点名，念到你的名字 | 你可以应“在”；孩子在台上喊“桥在我在”，你和玩家都知道那一夜真正喊的是什么 |

## 七、紧迫感不靠倒计时

一篇对《博德之门3》早期测试版的评论指出，“脑袋里的寄生虫”让每个任务都有来由，也有它自己的缝隙：既然时间紧迫，为什么还能随便睡觉？

归来的紧迫感用已公布的事件承担。每个阶段都有一个角色说出口的、章节推进才会触发的事：监察船将到岛、鲁斯会在那之前拆散转运、会盟开幕、回澜关封航。游戏时间不流逝，玩家闲逛不会让朋友死亡，但角色会说“现在不是歇的时候”。到了 M08，主线才第一次允许休息和庆祝，这一晚因此显得珍贵。

## 八、四张海报画面

做出来才有“想玩”的冲动，要提早进美术需求：

1. 你的手按在刻着自己名字的石头上。
2. 火光里甩开的断缆。
3. 沈砾站在巨大的泵机前，拍着机壳。
4. 雾里一排船，钟楼上的钟在敲。

## 九、会让玩家放下手柄的地方，以及对策

| 风险 | 对策 |
| --- | --- |
| 开场太安静，只有纪念日小品 | 先玩 P0，再进 M00，小品因此有了反讽 |
| 名字和政治词太多 | 前十五分钟只出现三个名字，国名放到 M02 以后 |
| 宣传里提前泄露“她已经在组织修理班” | 预告片只展示“救她”，反转留给 M05 之后 |
| 中段救出沈砾之后动力不足 | M08 夜里的“她早就知道”、M09 的两份名单、M12 的真相选择，三个新问题接力 |
| 玩家不知道“领人”具体做什么 | P0 让玩家在前十分钟做过修理、救人、动手；调查缆口和谈判在 M02、M03 很早出现 |
| “一个个领回来”只有一次 | M08 之后开放五条名册案，每条一个小故事，以点名收束 |
| P0 太长，玩家没玩到第二章就走 | 压到十分钟左右，第一分钟内就有操作，可跳过对话 |
| 试玩版结尾没有悬念 | 试玩版终点定在 M03，陆钧说“我知道桥三更断，我没说” |

怎么在做出来之前验证这些，见 [VALIDATION_PLAN.md](VALIDATION_PLAN.md)。

## 十、书名

“归来”是工作标题，用词很泛，在商店页搜索里容易被淹没。可选：《点名》，或副标题“他们说你们死了”。

我只做了一次英文搜索（Roll Call），没有查到同名的独立游戏，只查到《Prison Tycoon》的一个叫 Roll Call 的 DLC，其余是新闻媒体和电视预告片的用法。这不是正式排查。定名前请在 Steam、TapTap 和商标库里查中文名与英文名，中文名“点名”我没有搜过。

“归来”还有一层可以用的出处：《楚辞·招魂》反复呼喊“魂兮归来”，招魂有招生者之魂与招死者之魂两种（据中国作家网上的两篇文章）。本作的点名、唤名、雾里叫名字，正是现代版的呼唤。副标题“魂兮归来”太古典，我不建议直接用，可以当作卷首引文，或放在尾声里。
