# M03 · 海边的旧军旗（可朗读场景稿）

“归来”为工作标题。本稿承接 [STORY_OUTLINE.md](STORY_OUTLINE.md) 与 [CHARACTERS.md](CHARACTERS.md)。方括号是玩家选项或操作。

> **出场人物**：你、陆钧、缺腿的老兵、做木匠的旧兵、矿区线人。
> **读取事实**：`bridge_evidence`。
> **写入事实**：`lu_confession`（早问 / 带证据晚问 / 未问）、`voyage_path`。
> **章末留给玩家的问题**：陆钧为什么主动承认？他要我替他守什么？

---

## 一、滩涂上的旧部与每晚三十个名字

**傍晚。海边。** 一片收了网的滩涂上，**陆钧**的旧部在列队，不到两百人，穿的不是军服，是各种颜色的旧衣，只有袖口缝着同一条蓝布。

列队前，陆钧正替一名缺腿的老兵付医费，不看纸条，一口气念得出那人全家的名字。
另一个已经做木匠的旧兵走过来，把一袋捐给弟兄的钱放在木箱上，低声说自己不肯再穿军服了；陆钧点点头，没有勉强，让他走了。

[操作：探访营地里的矿区线人，查赤盐矿区潮道、取替代登陆资料]

**天色暗下来。** 陆钧站在队前，手里一本很旧的册子，翻开着。他没有低头看，他记得。

陆钧：第三旅，一营。赵得福。

队里有人：在。

陆钧：钱满仓。

（没有人答。他停了一拍。）

陆钧：钱满仓。

（还是没有人答。）

陆钧：钱满仓。

（三遍。没有人答。他在册子上轻轻点了一下，没有划，接着念。）

一个老兵站在你旁边，压低了声音。

老兵：每晚三十个，不论生死。念完一整本要三十七个晚上。他念了好几遍了。

---

## 二、你问，他答

**点名结束，队散了。** 陆钧把册子合上，朝你走来。

陆钧：你来得比我预想的早。

[“我来问桥。”]
[“你念的那些名字，有我的。”]
[“我需要一条船。”]

（三个选项不能强制通向同一场问桥。**仅选“我来问桥”时才播放下面的断桥问答**：若在 M02 已有 `bridge_evidence`，记录 `lu_confession = 带证据晚问`，否则记录 `lu_confession = 早问`。只谈名册或船则记录 `lu_confession = 未问`，跳过以下问桥对质，M12 时由陆钧主动说出真相。）

**`[仅选“我来问桥”时]`**
陆钧：你问。

你：桥是谁断的？

陆钧：总帅令。三更。工兵队。

你：你知道。

陆钧：我知道。

（他没有躲开你的眼睛。）

陆钧：你想知道我为什么没说。

你：我想知道。

陆钧：那天晚上我接到命令，第三旅不撤。三更断桥，不能告诉任何人。我是旅正，我接了。

陆钧：我数过。桥这头一万四千，桥那头一千一百。我没说，是因为我说了，防线天亮前就会散在黑里，一千一百人死在黑里。我没说，天亮以后，还有人排队投降。

陆钧：**我用他们的不知道，换了他们的命。**

**`[若选“你念的那些名字，有我的”]`** 陆钧把册子翻到你的名字：“我没划。你要我划，也得你自己说。”不触发总帅令披露。

**`[若选“我需要一条船”]`** 陆钧先谈潮道、护卫和旧军旗的条件，容你暂不问旧案。此前未问的断桥真相仍留到 M12。

**`[以下“十二年没睡好”、玩家追问和第三节保密请求，仅 `lu_confession != 未问` 时出现]`**。如果玩家只谈名册或船，则跳过这些话，直接进入第三节的出海渠道选择，不会在没听断桥自承时突然替陆钧守秘密。

（海风把他袖口的蓝布吹了起来。）

陆钧：这个选择，我十二年没睡好。

[“你该说的。”]
[“你替他们决定了。”]
[（沉默）]

**如果你说“你该说的”：**
陆钧：对。我每晚都在想这句话。你让我现在去说，他们会问我，为什么现在才说，我答不上来。

**如果你说“你替他们决定了”：**
陆钧：是。（停）我到现在还在替他们决定，你看出来了。

**如果你沉默：**
（他等了很久，没有开口，也没有催你。）

## 三、他的请求与出海选择

**`[仅已问桥且 lu_confession != 未问时，播放以下请求与三种回应]`**
陆钧：有件事，我想请你。

陆钧：他们的家人，以为自己的儿子是死守桥头的英雄。你拿走这个，他们什么都不剩。

陆钧：别告诉他们。

[“我不会告诉他们。”]
[“我还没决定。”]
[“我不能答应你。”]

**如果你说“不会”：**
陆钧：谢谢。（停）不用谢我。你什么也不欠我。

**如果你说“还没决定”：**
陆钧：好。决定了，告诉我一声。我不拦你。

**如果你说“不能答应”：**
陆钧：那我也不拦你。（他把册子递给你看一眼）只是你去说的时候，先想想，每一个名字后面站着几个人。

**`[若 lu_confession == 未问]`** 陆钧只把矿区潮道、护航代价和旧军旗摆给你看：“要我出人，条件先说在前头。旧事等你愿意问，再来找我。”你不需答应替一个尚未听到的秘密守口；在 M12 仍可第一次听到他本人承认断桥决定。

> **【玩家抉择：前往赤盐的渠道（写入 `voyage_path`）】**
> - `[接受陆钧的旧军旗与护航：有护卫与线人，但公开挂旧军旗（voyage_path = 陆钧护航）]`
> - `[有限合作：只取潮道资料与线人联络，结合韩峤或祁雀渠道（voyage_path = 混合 / 韩峤船坞）]`
> - `[谢绝旗号：带着他的话离开，单走祁雀的隐蔽商路（voyage_path = 祁雀商路）]`

## 写作笔记

- 陆钧的话全是数字和事实，从不用形容词。他的难受只出现在停顿和袖口的蓝布上。
- M03 里不要让玩家被他说服，也不要让玩家被他吓到。他只是一直在等你问。
