# M10 · 镜湾的邀请

> **章节定位**：第三幕政治分赃桌、三联名册拼写对账高潮与回澜封航事变。
> **核心目的**：撕掉“清官断案”的温情假象——让伊蕾展现出强迫症官僚的冷幽默与自保本能；将名册核验实装为可动手的**【三联单方言谐音/俗字比对面板】**；在二楼高梯账房与韩峤展开“涂改三次的名字 vs 四十一笔死契赎人账”的巅峰潜台词对质，并让战报底稿的三选一各自背负沉重代价。
> **出场人物**：你、伊蕾、韩峤、沈砾、蕊亚、三位识字矿工、矿主代理人（或鲁斯账房/易达）、陆钧使者。
> **读取事实**：`identity_reveal`、`m02_clue_draft`、`rus_status`、`rus_ledger_saved`、`survivor_yida`、`rc01_ration_book`、`rc02_resolution`、`rc04_resolution`、`rc05_third_squad`。
> **写入事实**：`world_notices = 3`（“桥在我在”征召令）、`han_ledger_use`、`roster_accuracy`。
> **章末留下的问题**：韩峤那份战报我拿它换了什么？回澜关被陆钧封航扣船了，怎么破局？

## 第一场：第三则预兆与“发臭的公事房”

**【画面】**
离开临潮前往镜湾那天清晨，临潮渡口墙上贴出一张墨迹未干的**征召告示**（`world_notices = 3`）。
告示最上方印着四个大字：**“桥在我在”**，落款是**陆钧**。
你站在墙根下停住脚步——十二年前白水渡桥头上，你喊的是“谁带了多余的绳子”。你从没说过的那句话，如今成了别人招兵买马的口号。

**【镜湾商会大厅】**
中立商贸城镜湾，商会大厅正中并排摆着三张长桌：矿主与边防强硬派、监察官**伊蕾**、以及韩峤与陆钧的代表。
桌上摊着两本发霉的瑟兰文转运册，伊蕾正用一把小银刀刮掉纸上的霉斑，头也不抬（`Anim: 伊蕾_Scrape_Paper`）。

伊蕾（刀尖停在第 47 行，语气冰冷）：刚才矿主递来的那份文件，要求我盖章证明这批人还活着——而下面附的佐证材料，是他们的死亡证明。

- `[条件（rc02_resolution == 2）：若在 RC-02 用例外条款默认了石棱冒名]`
  矿主代理人突然拍案而起，举着抄件发难：“伊蕾监察官，贵处前几天刚用‘例外条款’放行了一个连臼齿都对不上的混血冒牌货！今天这批移交名册，我们要求全部冻结重审！”（你的初始谈判筹码下降，伊蕾不得不当场签下连带担保才压住场面。）

## 第二场：一个人的名字（实机“三联单拼写对账面板”）

**【画面与伊蕾的黑色幽默】**
M09 夜航接驳的人船刚靠岸，**蕊亚**带着家人被拦在登记台前——**晏国战死名册的音译、瑟兰矿营的拼写、以及东岸渔市的口头证词，三处写的是同一个人，拼法却全对不上**。
伊蕾走下台阶，去码头叫来了**三位识字的矿工**，搬来小板凳在大厅角落摊开三本厚册子。

伊蕾（瞥了你一眼，`Portrait: 伊蕾_Deadpan`）：别用那种感动的眼神看我。我连夜帮你们对拼写，不是可怜这帮满身虱子的矿工。

伊蕾：是因为上个月有个蠢货文书核错了三个字母，人被遣返死在船上，臭味飘进了我的公事房，害我写了十七份检讨。我不能把没写下来的事当成发生过——但我可以替你把它写下来。

**【玩家操作：三联单拼写与谐音对账 UI（写入 `roster_accuracy`）】**
屏幕并列展开三栏档案，玩家利用“镜湾方言前后鼻音不分、瑟兰尾音辅音脱落、矿营简笔俗字”三条规则卡，手动拉红线连接同一人（每连对 3 组执行一次《奥伯拉丁》式锁定）：
1. **第一组**：官署阵亡录【江木】 ↔ 矿营花名册【姜阿穆（尾音多一辅音 m）】 ↔ 蕊亚渔市账本【三号船舱姜老四（左肩烙印）】；
2. **第二组**：官署阵亡录【侯七】 ↔ 矿营花名册【猴漆（俗字谐音，洗矿班单数编号 17）】 ↔ 家书信封【门槛修好了的木匠】；
3. **第三组（文字诡计）**：官署主簿故意把【戌字三号】与【戊字三号】拆成两个死人名字吃双份空饷，玩家比对笔迹勾出合并！
- **【成败反馈】**：全对锁定（`roster_accuracy = 2`），蕊亚及整批归还者当场拿到合法移交红章；若漏看“戌/戊”笔误草率提交（`roster_accuracy = 0`），误认的 3 人被暂扣至下一批窗口，且在 M12 会被官署拿来反咬一口。

## 第三场：二楼木梯上的对质——涂了三次的名字与三向反噬

**【画面与高低机位调度】**
核验间隙，你走进港务司偏厅二楼账房。
**韩峤**站在二层通顶的旧档木梯高处（`Actor: 韩峤` 位于高处 Tile，玩家在楼下仰视），手里捏着算盘，头也不回地抽出一卷发黄的防汛粮册扔下楼，砸在你脚边（`SFX: Book_Drop_Heavy`）。

- `[条件（identity_reveal == 3）：若 M00 等到第三遍才应声]`
  韩峤（在木梯高处背对着你）：那天在碑前，你等了三遍才答“在”。我数了。

你把 M02 拿到的**涂改战报底稿**（及若完成 `RC-01` 拿到的《炊事班领粮实录》、`RC-04`《死礁水文图》、`RC-05`《矿狱强征手令》）拍在桌案上。

你：十二年前你从白水河里爬上来，手还没干，就在“敌军火攻毁桥、全员殉国”的战报上签了字。

韩峤（在木梯顶上拨了一下算盘）：回澜关十二年前冬季防汛，入库糙米四千六百石，霉变折耗八百石。我要是不在“阵亡抚恤核销单”上按那个红印，开春整个南岸渡口连半粒救济粮都批不下来。——你拿把刀架在我脖子上，四千六百石也不会变成五千石。

你（翻开桌案暗格里那本私账的末页）：那这四十一笔“死契转脚夫”的买路钱，也是防汛折耗？韩大人，港务司什么时候做起替死人赎身的赔本买卖了？

韩峤从木梯上一步步走下来（`Move: Step_Down_Ladder`），一把夺过那本私账，“啪”地合上，声音冷硬如铁（`Portrait: 韩峤_Stern_Cold`）。

韩峤：少往我脸上贴金。码头缺熟练的装卸工，从苦役营赎几个懂水性的旧卒回来抵船贷，工钱能压三成。这叫平账，懂吗？

> **【玩家追问：`[对话]` 直刺心防】**
> - `[“那最后一页第 42 行，我的名字被你用浓墨涂了三层、连纸背都刮毛了——工钱也能压三成？”]`

韩峤的拇指在算盘框上猛地一掐，一颗算珠“啪”地崩断掉在地上（`SFX: Bead_Snap`）。
他沉默了足足三秒。

韩峤（声音沙哑却残酷）：涂了三次，是因为前两次鲁斯开价太高，我手头的脏钱只够先赎断了手的木匠和快瞎眼的铁匠，排不到你！

韩峤：你想让我当年怎么写？写“统帅陆钧下令砍桥，参军韩峤临阵生还”？那张纸递上去，你们留在东岸的一千一百号人立刻会被打成“弃守溃兵”——溃兵家属不仅没有一文钱抚恤，还要罚没田产！我签那两个假字，换了临潮三百户孤儿寡母十二年的口粮，换了我坐在这个脏位置上用走私税赎回来四十一条命！

> 门外走廊上，**沈砾**和**伊蕾**正好走过来停在半掩的门边。
> 伊蕾（指了指偏厅烧得正旺的火盆，低声提醒）：督办和商会只认原件。你把底稿钉出去，韩峤今晚就进大牢；你拿原件进去跟督办私下换一号泊位，火盆一烧，死在桥下的人就永远没证据了；你要是替韩峤把原件烧了保他，咱们今晚就得去外滩烂泥湾顶着北风抛锚。你定。
