# M14 · 同一个海峡，不同的进场（可朗读场景稿）

“归来”为工作标题。本稿为第四幕终局行动，承接 [STORY_OUTLINE.md](STORY_OUTLINE.md) 与 [CHARACTERS.md](CHARACTERS.md)。三条进场共享同一个空间：回澜关、近岸码头、旧运渠和外海接应点。方括号是玩家选项或操作。

> **出场人物**：你、沈砾、祁雀、阿鸢、欧林、小七、陶霁、陆钧、伊蕾、韩峤（及名册案支援者）。
> **读取事实**：`lu_confession`、`rc04_ding_yue`、`rc05_third_squad`、`conscription`、`landing_capacity`。
> **写入事实**：`crew_ayuan`（安全 / 重伤退出 / 没能回来）、`conscription`、`landing_capacity`。
> **章末留给玩家的问题**：三条路，哪一条才是回家？

---

## 路线 A：监督移交与民用通路（主结局：以姓名归来）

**白天。回澜关广场。**
你带着可核验的名单、实际接纳地、**伊蕾**的监察和**韩峤**（或中立商会）的港务担保走进广场。**沈砾**、**欧林**与**小七**守在广场西侧的码头栈桥边，随时接应愿意登船的人；**陶霁**带着船工护住登船跳板。
广场上，被扣的人分成两队：**想走的站左边，想留的站右边**。有一个穿旧衣的人站在中间，左右看了很久。

你：今天不替任何人点勾。你们每个人当众回答——“**我想走，还是想留**”？

那个站在中间的人看了一眼船上的家眷，迈步走到了左边。
东侧拒绝放行的军械班上前阻拦，你带人通过局部武力或铁证交涉将其压住。**陆钧**站在高处看着走空的半边广场（结合 `lu_confession` 与你在 M12 的对质结果），失去了部分旧部支持，最终被解除指挥、被拘押，或带着自愿留下的人退出关城。
- **可见代价**：你承担公开责任、接受军械限制、偿还供给或让出商业泊位，部分旧军不再信任你。

---

## 路线 B：武力打开归途（主结局：军旗下的归途）

**夜。回澜关钟楼。**
按照你在 M11 与 M13 定下的分工，**沈砾**与**欧林**带着**小七**从外侧水道潜入，反手打开关内暗锁、卡死封港铁栅的绞盘机械；你带人趁夜突入信号钟楼，解除关内封锁军械。
冲上钟楼顶层，你一把握住钟绳，心里数到三：

你：**一、二、三。**

**【当——当——当——】**
你敲响三下铜钟。这一次的信号是**“开门”**。
关门打开，你掩护愿意退出的人登船。

> **【玩家抉择：关门打开后的军事选择（写入 `conscription`）】**
> - `[只掩护愿意退出的平民与旧部上船，不扩大战事]`
> - `[借陆钧的力追击、夺占沿岸仓区：改变会盟处境和边境力量，但付出伤亡、修复与贸易受损代价]`

---

## 路线 C：中立安置与绕行（主结局：在别处开始）

**夜。旧运渠，大雾。**
浅底船队驶入旧运渠。**沈砾**、**欧林**与**陶霁**提前在旧运渠水闸处拆开锈死的闸栓，为你打开水道；领航船头把**祁雀最丑的那只黑泥杯子**套在灯外，当作识别灯。

[操作：雾中点名领航（若完成了 RC-04 学会听雾加成，雾中接应更稳）]

你站在领航船头，向雾里报出第一条接应船船长**祁雀**的名字。
浓雾里传来祁雀的声音：**“在，账上记着。”**
紧接着，每条船报出一个名字，一条接一条地应一声：**“在。”**——这是你们在雾海里的航标。
你们接走愿意离开的人，分批送往中立城**镜湾**。
- **可见代价**：背负借贷、长期劳动合同、家属分批团聚、暂时不被晏国官方认可；但这里有真实的新生活，不是低配结局。

## 阿鸢的高风险位置结算（写入 `crew_ayuan`）

在路线 B 的信号绳或路线 C 的运渠口闸处，舵手**阿鸢**守在必守的位置：
- **若你在 M13 投入了足够的准备**（人手、替代通路、事先布置的接应）：阿鸢在接应下顺利撤回船上，**一定活着**（`crew_ayuan = 安全`）。
- **只有在你已得到祁雀明确警告、准备不足，并在 M13 单独明确选择仍坚持让他上时**（仅确认路线 B／C 不足以触发）：阿鸢为了守住闸口，可能重伤退出航行（`crew_ayuan = 重伤退出`），或没能回来（`crew_ayuan = 没能回来`）。
（战斗失败后的重试不改变此结果。）
