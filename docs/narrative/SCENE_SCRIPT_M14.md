# M14 · 同一个海峡，不同的进场

> **章节定位**：第四幕终局行动，三条路线共享同一海峡空间（回澜关、近岸码头、旧运渠、外海接应点）。
> **核心目的**：让玩家选择的归途真正落地为可操作的终局关卡；将舵手**阿鸢**的高风险牺牲机制从“单点盲盒”升级为**【三重汇聚锁（Convergent Lock）+ 双重明示路标】**；同时兑现 `RC-01`（热食补给）、`RC-02`（石棱重锤队）、`RC-03`（白矶岛淡水与爆破组）、`RC-04`（丁岳声呐引航）、`RC-05`（第三班七活五魂奇袭）的终局支援。
> **出场人物**：你、沈砾、祁雀、阿鸢、欧林、小七、陶霁、陆钧、伊蕾、韩峤（及各名册案支援角色）。
> **读取事实**：`m14_route`、`skill_fog_mastery`（Key 1）、`m13_stern_shield`（Key 2）、`m07_extra_miners` / `rc03_baiji` / `rc05_third_squad`（Key 3）、`han_ledger_use`、`rc01_chen_yan`、`rc02_resolution`、`rc03_baiji`、`rc04_resolution`、`rc05_third_squad`。
> **写入事实**：`crew_ayuan`（`0`=安全, `1`=重伤退出, `2`=没能回来；战后提交防重试污染）、`m14_conscript_outcome`。
> **章末留下的问题**：船靠岸了，石碑前最后一次点名，谁在场、谁应声？石碑上最后写什么？

## 前置核心机制：阿鸢生死的“三重汇聚锁”与双重路标（路线 B / 路线 C 触发）

**【三重汇聚钥匙（3 Keys to Survive）自动核查】**

1. **Key 1（听雾宗师）**：`skill_fog_mastery == true`（完成了 `RC-04` 死礁辨音与阿鸢破雾歌，阿鸢能靠双耳回音提前 1 秒预判弩矢破空声）。
2. **Key 2（船尾铁叶挡板）**：（`m13_stern_shield == true` 或 `st06_state == 1`）（前者是在 M13 将北岭冷锻铁叶分配给船尾副舵，后者是 ST-06 陶霁完成姑侄合伙的舵榫加固；不能将 ST-06 的结果直接冒充 M13 的选择）。
3. **Key 3（岸上信标与工兵掩护）**：`m07_extra_miners == true`（`M07` 救出的后山滑道二十名矿工在回澜关外滩点亮偏航信标）或 `rc03_baiji == 1` / `rc05_third_squad == 1/2`（白矶岛矿工爆破组/钟岭第三班吸引城头弩炮火力）。

## 路线 A：监督移交与民用通路（对应主结局：以姓名归来）

**【画面】**
清晨。回澜关中心广场，四周站着手持镜湾监察旗帜的**伊蕾**、民用船队代表，以及**陆钧**旧部。广场正中用石灰画了一条白线。

**【核心场面：当众自己选】**
你走到白线前，举起扩音铜筒高喊：
“今天不点名，也不按军籍！**想回家的、想跟着民用船队去镜湾过日子的，站左边；自愿留在关内跟着陆统领的，站右边！**”

人群开始移动——几十个抱着包袱的工匠和家属快步走到左边；十几个年轻旧兵咬咬牙站到了右边；一个穿破军服的汉子站在白线正中间，左右看了很久，最后看了一眼抱孩子的妻子，慢慢挪到了左边。
陆钧的副手拔刀拦在东侧军械班出口：“没有统领手令，左边的人一个不许登船！”

> **【玩家操作与名册案支援】**
> - 你展开伊蕾盖印的核验名册与泊位文书；若 `RC-02` 保全了**石棱**，他会率领 6 名混血前债工持重锤顶住关闭的闸门；若 `RC-01` 保全了**陈砚**，他推着滚烫的炒盐葱油饼车在栈桥后方接应伤员。
> - 击退顽固军械班后，二楼廊檐下的陆钧看着走空的左半边广场，解下佩刀递给副手：“按伊蕾的程序走。”
- **代价**：你签下公开责任书、接受军械限制与长期供给债务，部分盼着收复故土的旧军冷冷看着你转身离去（`m14_conscript_outcome = 0`）。
