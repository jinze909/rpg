# M14 · 同一个海峡，不同的进场（可朗读场景稿）

“归来”为工作标题。本稿为第四幕终局行动，承接 [STORY_OUTLINE.md](STORY_OUTLINE.md) 与 [CHARACTERS.md](CHARACTERS.md)。三条进场共享同一个空间：回澜关、近岸码头、旧运渠和外海接应点。方括号是玩家选项或操作。

> **出场人物**：你、沈砾、祁雀、阿鸢、欧林、小七、陶霁、陆钧、伊蕾、韩峤（及名册案支援者）。
> **读取事实**：`lu_confession`、`shen_relation`、`rc04_ding_yue`、`rc05_third_squad`、`conscription`、`landing_capacity`、`crew_ayuan_risk_acceptance`、`crew_ayuan_assignment`、`final_route_choice`。
> **写入事实**：`crew_ayuan`（安全 / 重伤退出 / 没能回来）、`conscription`、`landing_capacity`、`civilian_exit`（真实自愿进退与人数）、`border_force_action`（止于护送 / 追击占仓 / 未走B）、`final_passage_outcome`（监督移交成立 / 武力通路成立 / 中立安置成立 / 待补救）。
> **章末留给玩家的问题**：三条路，哪一条才是回家？

---

**主结局的判定规则（先写结果，后演尾声）**：M13 的 `final_route_choice` 仅决定进入下述哪条行动；通路未核验时，`final_passage_outcome` 为 `待补救`。改线只重核还需要接应的人和后续通路；已安置的人、已有伤损与军事行动照实保留。只有实际有可用通路、已落实乘员自愿进退、可承载的航次/安置地，才能按相应路线分别写入“监督移交成立”“武力通路成立”“中立安置成立”。只占钟楼、取得纸面签字或发出邀请而无人获准离开，都不算达成。局部借用另一条路线的手段不自动切换主结局；若本线受阻，展示分批/担保/替代行动补救，或让玩家显式回 M13 改选并重新复核高风险门禁，不能用未完成状态进入 M15 领取任一结局。

**三条路线共用的在场条件**：下述沈砾操作机械、带队接应的描写，均仅在她实际同行且愿意承担该任务时成立。若 `shen_relation` 已明确决裂或不同行，改用 M13 已确认的船工、当地修船铺或付费拖船承担相应工作并支付资源与战术代价；不能一边写她离队，一边让她无条件出现。其他同伴也按实际可参与状态落实，不以预设演员名单覆盖玩家选择。

## 路线 A：监督移交与民用通路（主结局：以姓名归来）

**白天。回澜关广场。**
你带着可核验的名单、接纳地、M13 **真正落实**的监察与港务担保走进广场：伊蕾仍参与时使用她的副本，否则用已确认的中立监察；韩峤仍愿担保时使用其凭证，否则用真实商会担保。沈砾、欧林、小七各自愿意且到场时才守在栈桥边；陶霁愿意且到场时才带船工护住跳板。缺席岗位由 M13 的替代船工补上，不强行召回同伴。
广场上，被扣的人分成两队：**想走的站左边，想留的站右边**。有一个穿旧衣的人站在中间，左右看了很久。

你：今天不替任何人点勾。你们每个人当众回答——“**我想走，还是想留**”？

那个站在中间的人看了一眼船上的家眷，迈步走到了左边。
东侧拒绝放行的军械班上前阻拦，你带人通过局部武力或铁证交涉将其压住。**若陆钧实际仍在关内并能目睹**，他站在高处看着走空的半边广场，失去部分旧部支持；若已被控制或离开，只保留可核验的责任与处置结果。只有核验到实际愿意去留者、监督副本、接纳地、放行和登船安排均落实，才写入 `civilian_exit = 已核实自愿进退及人数`、`final_passage_outcome = 监督移交成立`。陆钧可能被解除指挥、被拘押或带着自愿留下的人退出关城，须按其强征责任、证据与实际政治处置选其一，不能三种结果同时发生；若无伊蕾/韩峤支持，使用 M13 已落实的中立监察与商会担保。未获放行则保留 `待补救`，先用这些渠道谈判、保护离开者或由玩家明确改线。
- **可见代价**：你承担公开责任、接受军械限制、偿还供给或让出商业泊位，部分旧军不再信任你。

## 路线 B：武力打开归途（主结局：军旗下的归途）

**夜。回澜关钟楼。**
按照 M11 与 M13 **已实际确认**的分工，并确认船队和关内接应已收到三声钟“开门”反号，沈砾若同行、欧林和小七若各自愿意且到场才参与外侧水道潜入；其他岗位由 M13 已确认的替代工匠与船工开暗锁、预备在开门后卡住绞盘，防止铁栅再落下。你带人突入钟楼解除封锁军械。反号尚未通知成功时不能直接敲钟并假称船队理解。
冲上钟楼顶层，你一把握住钟绳，心里数到三：

你：**一、二、三。**

**【当——当——当——】**
你敲响三下铜钟。这一次的信号是**“开门”**。
关门打开，你掩护愿意退出的人登船。

> **【两项独立核验：先问本人，再决定是否追击】**
> - `[让被扣的人分别确认“离开、留下或继续从军”，对不愿入伍者落实脱离控制、船位与接纳地（写入 civilian_exit 的实际名单和人数）]`
> - `[暂不能核验或安置这批人：先补登记、接应与运力；即使已经夺钟楼也不能宣称获得主结局（civilian_exit = 待补救）]`
>
> **【玩家抉择：是否在已保障平民退出的前提下扩大军事行动（写入 `border_force_action`；`conscription` 另按实际强征记录）】**
> - `[止于打开通路与护送，停止追击（border_force_action = 止于护送）]`
> - `[在已兑现自愿进退后继续追击、夺占沿岸仓区；付出伤亡、修复与贸易受损，陆钧是否出力依实际合作状态，不能凭过去拒绝合作仍无条件借兵（border_force_action = 追击占仓）]`
>
**核验后果**：仅在关门真实开放、至少一批有意愿的被扣者已获安全退出与实际接纳安排时写入 `final_passage_outcome = 武力通路成立`；否则为 `待补救`，先补可执行的船位、援护或替代运输，或由玩家明确返回 M13 改线。行动已发生就立即入账。一次追击后的改线仍保留占仓、伤损和贸易影响；已经安全离开的乘员在新路线只查去处，无须再登一次船。

## 路线 C：中立安置与绕行（主结局：在别处开始）

**夜。旧运渠，大雾。**
浅底船队驶入旧运渠。沈砾若同行、欧林和陶霁若各自愿意且到场才拆卸运渠锈闸；缺席岗位由 M13 已确认的替代工匠补上，开闸并不凭空完成。领航船头若仍有 M04 确实随行的那只黑泥丑杯，才套在灯外作识别灯；否则用船队事先约定的普通遮光识别灯，不让杯子瞬移。

[操作：雾中点名领航（若完成了 RC-04 学会听雾加成，雾中接应更稳）]

你站在领航船头，向雾里报出第一条已确认接应船船长的名字。若祁雀仍同意带船且在场，你叫的是**祁雀**，雾里传来她的声音：**“在，账上记着。”**；若她拒航，则叫已落实的替代船长，由那名船长亲自回应，不播放祁雀的声音。
紧接着，每条船报出一个名字，一条接一条地应一声：**“在。”**——这是你们在雾海里的航标。
你们只按已实际落实的多航次、接纳床位与船工意愿接走愿意离开的人，分批送往中立城**镜湾**；尚未接上船或仍在别处的人留在名册待安排，不能默认已全员到港。中立安置处实际接纳首批人并确认后续安全分批航次后，写入 `civilian_exit = 已核实自愿进退及人数`、`final_passage_outcome = 中立安置成立`；若运渠或泊位受阻，先付额外运力/改期/分批的真实代价，不在只看到航标灯时就宣布结局。
- **可见代价**：背负借贷、长期劳动合同、家属分批团聚、暂时不被晏国官方认可；但这里有真实的新生活，不是低配结局。

## 阿鸢的高风险位置结算（写入 `crew_ayuan`）

在路线 B **钟楼下层连通关门机构的联动信号绳**（与主角敲钟的钟绳不是同一根），或路线 C 的运渠口闸处，只有 `crew_ayuan_assignment = 本人自愿值守` 才由阿鸢守住必守位置；若是 `已落实替代班组`，则按已确认的安全接应由替代人员完成，不能强行派阿鸢赴险。**路线 A 不派阿鸢去 B/C 高风险哨位。**
- **若此前已在本次终局行动结算重伤或没能回来**：补救、改走 A 或再次进场都沿用已有结果。余下的岗由已落实的替代人员接手。以下只结算尚未受伤或失联的阿鸢。
- **若路线 A，或路线 B/C 且 `crew_ayuan_risk_acceptance = 已补齐准备`、且岗位与接应确已落实**：阿鸢不被派往无接应的高风险位置，或在完整接应下顺利撤回船上，**一定活着**（`crew_ayuan = 安全`）。
- **只有路线 B/C 且 `crew_ayuan_assignment = 本人自愿值守`、`crew_ayuan_risk_acceptance = 准备不足但明确接受`**：在原定的安全撤出窗口已经错过、阿鸢仍自愿守住岗位时，播放一次**不能靠战斗重试改变的行动抉择**。这不是暗骰、随机死亡或路线 B/C 的自动惩罚：
  > **【玩家抉择：最后一段撤出机会】**
  > - `[立即组织剩余接应人手尽力拉阿鸢撤出：他活着但重伤退出航行（crew_ayuan = 重伤退出）；撤离时间、船位与修复代价实际增加，须重核 civilian_exit 与最终通路。若因此通路未成立，进入待补救而不是虚报胜利。]`
  > - `[在已知无法及时折返救人的前提下，维持接应通路，让阿鸢独自守到最后：他没能回来（crew_ayuan = 没能回来）；保住的航次与人须实际核验，无法抹去自己当初接受风险又放弃最后接应的决定。]`
  > （两项均须在 M13 已独立接受高风险且阿鸢本人自愿值守后才出现；队友可拒绝被强派去补救。若玩家在 M13 已补齐安全准备，本段绝不触发。此处写入的永久后果与具体补救成本随叙事存档，不随战斗胜负或读档刷奖励改写。）
- **若岗位 `未落实`，或风险字段缺失/仍为 `未确认`**：M14 不得开始 B/C 高风险行动，返回 M13 补齐准备或改走路线 A；不能由 M14 默认推定玩家接受风险。
（战斗失败后的重试不改变此结果。）
