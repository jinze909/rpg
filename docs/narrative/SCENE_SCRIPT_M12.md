  1. **你（零四二）**：“十二年的迷雾彻底散尽了——**十二年前冬月十七断桥夜**，督粮道掌印**钱镠**为填补四万石霉米死罪，与东岸赤盐矿主**鲁斯**勾结下达锯桥密令；参军**韩峤**为保南岸防汛粮盖下缺角印调开北岸巡哨，放水鬼在**前半夜戌时三刻退潮时**锯断北缆三分之二，导致桥北一千一百名弟兄落水被鲁斯捞走充矿（韩峤事后愧疚十二年，才克扣抚恤私下赎回41人）。”
  2. **【沈砾 · 断桥重钳工头】**：“带兵的**陆钧**在戌时四刻巡桥摸到了锯口，为了保住刚过河的一万四千主力不因黑夜断粮哗变踩踏，在**半夜三更**挥刀砍断最后三分之一缆绳，替韩峤独背了十二年冷血砍桥的骂名；而到了**八年前停战卖俘那年**，**伊蕾之父**与韩峤联署盖下《转债劳务附款》，把幸存的三百九十三人抹去军籍、永远钉死在盐矿里！”
  3. **【祁雀 · 雀行号女船主】**：“四个人，四双手，四份铁证全在咱们手里！今夜守过**白矶灯塔与死礁**最后一夜寒潮，明早直闯**西岸家乡临潮港白水渡**，当着全城百姓的面砸碎那块假死人碑！”


- **【陆钧退场宿命绝唱（断刀与三十七夜孤钟之囚）】**：
  - **【陆钧 · 借刀背罪守桥将】**（低头看着帅案上那座被自己一刀斩断铜摆的慢半拍裂钟，花白头发在海风中散乱，声音苍凉如铁锈摩擦）：
