## 一、钟楼下对质

**回澜关。钟楼下。** 你从关外交去一张约谈条，请当面核对扣下的船票。陆侧守军带你过岗，收了通行签，只答应会面后原路放你出去。钟楼的门开着，**陆钧**一个人站在台阶上。

陆钧：你一个人来的。

（仅当沈砾实际留在关外看船时）
你：沈砾在外面。

陆钧：岗哨说她在外面守船。好，你听我把账念完。

（她没有在关外看船时，直接从钟声说起。）

（他看了一眼钟。）

陆钧：这钟，三下。你听见的时候，是不是也会数？

[“会。”]
[“你怎么知道？”]
[（沉默）]

陆钧：我也会。十二年，我每次听见钟声都数。

**他从怀里取出一册名单，一叠船票，一张借据。**

陆钧：这是我救回来的四百一十二个人。这是我借的船，每一条。这是还欠着的钱。

陆钧：这里面的名字，原先都等着一条回家的路。这是我给他们找的。

你把另一页放到他面前。上面是被他的副手收走船票的人的名字，还有被征用的几条私人渔船。

陆钧：那是我下的命令。不是副手失控，是我的命令。

（他没有看你放下的那页。）

陆钧：停战八年，赤盐还有人，白矶还有人。我没有一条船是干净的，没有一条路是干净的。我选了最快的那一条。

[“有人不想再打。”]
[“你把别人的路收走了。”]
[“你上次也是这么说的。”]（仅在 M03 已问过桥，即 `lu_confession != 未问` 时出现）

- **`[条件：若在 M03 未问过桥的事（lu_confession == 未问）]`**
  陆钧看着你，在此主动说出了十二年前三更断桥的总帅令：“那天晚上我接到命令，第三旅不撤，三更断桥。我没说，是因为我说了，防线天亮前就会散在黑里，一千一百人死在黑里。我没说，天亮以后还有人排队投降。我用他们的不知道，换了他们的命。”
- **`[条件：若在 M03 已问过桥（lu_confession == 早问 / 带证据晚问）]`**
  - **如果你选前两个（“有人不想再打”或“你把别人的路收走了”）：**
    陆钧没有辩解，只低声说：“我知道。这笔账记在我名下。”
  - **如果你选第三个（“你上次也是这么说的”）：**
    陆钧沉默了一会儿。
    陆钧：……是。上次也是这么说的。

陆钧：**桥这头一万四千，桥那头一千一百。我现在睡不着，还是会再数一遍。得数还是对的。**

（他抬头看钟楼。钟声响起时，他的嘴唇也在动。）

## 二、三方的难处与你的牌

回到关外据点，三方的难处摆在桌面上，没有哪一方的办法是没有成本的：
- **临潮港务署**：若韩峤已因公开战报去职，由现任港务人员执行检查。扩大军械检查，会误伤普通返乡者，粮路也可能被切断；
- **陆钧**：武力能迅速清掉押运威胁，也会给东岸再动员的借口；
- **伊蕾**：能监督移交，控制不了所有部队。
你摊开实际拿到的材料。韩峤签的战报能证明官府发过什么公文。缆口能证明怎么断的；桥夫的旧记录或目击证词能指到工兵和命令；陆钧刚才的话能证明他自己知情。漏查的材料就留空，仍可记录亲耳听到的自承。关内交涉另凭你亲眼见过的扣船、旧兵的回答和接应路线。

- `[条件：若已完成 RC-01、林素本人愿来且已到场]`
  **林素**会提起你当时的选择：**“你让他们知道，还是让他们安心，我是过来人。”**

## 三、三种立场如何呈现（M12 的选择，顺序随你）

渡口之夜的真相要不要公开？三种做法都要让玩家看见事实和代价，没有哪一个是明显的“好答案”；已决裂或离队的人不能只为凑齐三位发言者而被召回：

**沈砾（仅她仍参与时，主张公开）**
沈砾：我看过缆口。我不想让一千一百个人替一个谎言站岗。姜婶攒了十二年的单子。你把这件事说出来，人家一定要她再翻一遍。我知道她怕什么。我只是想你选的时候，什么都知道。

（若她不同行，公开路线仍可由玩家根据已有 `bridge_evidence`、战报底稿与证词提出，不借她之口说未说的话，也不因她离开而锁死这一选项。）

**姜婶（主张不公开）**
若姜婶到了关外，听她本人说；留在临潮时用实际送达的家书。她没有赴约或来信时，只按已知的抚恤登记谈代价。

姜婶：我不是怕钱。我是怕小豆长大了问我，她的英雄是谁。我得有一句话能答。

**韩峤与伊蕾（各自愿到场时谈“愿知者名册”）**
韩峤若愿出面作证：“愿意知道的人来问，我就告诉他们那天签了什么字。我签过一次，这次可以签我自己的证词。”

（若仍在任，他可以安排查档；若 M10 已去职，就以当事人身份作证，底稿由有权保管档案的人办理查阅。）

有权承担保管的伊蕾在场时，她说：“名册要有副本，要有能抽查的人。我可以做。”她缺席或已失去权限时，先请仍有权的监察方接收材料，办妥移交后才开放查阅。

> **【玩家抉择：渡口之夜的真相怎么处理（写入 `truth_disclosure`）】**
> - `[公开已有证词与确能核对的材料：家属重新面对旧碑与抚恤账，陆钧的旧部要重新判断他的命令，韩峤仍在任则去职，已经去职则以签字人的身份接受追问；姜婶按既有登记面对核账，已停发或已获准分期的账不重新起算；但终于有人知道亲人不是死在某个英雄桥头（truth_disclosure = 公开）]`
> - `[封存尚未披露的断桥材料：家属暂时仍能照原来的说法过日子，已经牵动的抚恤核查照办，你也得记着今天听到的话（truth_disclosure = 封存）]`
> - `[设“愿知者名册”：不强迫也不隐瞒，多数家属不会来问，来问的人要独自面对痛苦，且你得把实际掌握的副本或亲闻证词交给有权保管的人，查阅范围会成为会盟上的争议（truth_disclosure = 愿知者名册）]`

（**陆钧的信任回响**：若 M03 曾明确答应替他保密（`lu_secrecy_promise = 已答应`），现在选择公开或让愿知者查阅，就必须面对当初许诺与此刻决定不同的事实；陆钧可以不阻止，却不能毫无反应地当成从未有过承诺。若当时未决定或明确拒绝，不凭空算背诺；若 M03 未问桥，也没有守密承诺。封存则暂时守住对他的承诺，但无法自动解决家属与抚恤的旧账。）

（若 M10 已公开韩峤签名的虚假战报，M12 的“封存”只封存尚未公开的三更断桥命令与知情者，不会让 M10 已经发生的曝光、追缴或去职凭空撤销。反之，M10 只是私下交换底稿，也不等于 M12 真相已经公开。）

（带回已经核实的情报和接应记录。若交涉谈崩，原定通路记为受阻。回 M13 重新安排放行或替代水道，等 M14 确认有人平安出去后再结算通路。）

## 写作笔记

- 陆钧的话全是数字和事实，从不用形容词。他的难受只出现在停顿和袖口的蓝布上。
- M12 里陆钧不辩解、不求原谅，这是他最危险的地方：你找不到可以反驳的缝。
- “数到三”在 P0、M11、M12 各有回响，M12 是陆钧第一次与你共同数，不是全作最后一次；若 M14 选择路线 B，主角还会主动数三下、敲钟把旧信号改成“开门”。
