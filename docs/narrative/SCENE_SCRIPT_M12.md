# M12 · 一面旗帜不等于每个人

> **章节定位**：第三幕最高潮，三线交汇（外线回澜、内线关系、谜线渡口真相在此彻底碰撞）。
> **核心目的**：在钟楼帅帐用“三十只倒扣粗陶酒碗 + 染血三更令箭 + 偏执狂的逻辑闭环”完成与陆钧的巅峰对质；实装**【三轮甩账对质】**；随后通过交互式走位听取沈砾、姜婶、韩峤/伊蕾的三方陈述，并为选项 C“愿知者名册”装上**“猜忌瘟疫与祠堂内讧”**的锋利倒刺，彻底消灭中庸逃避陷阱！
> **出场人物**：你、陆钧、沈砾、姜婶、韩峤、伊蕾、林素（若完成 RC-01）。
> **读取事实**：`m02_clue_cable`、`m02_clue_log`、`m02_clue_draft`、`lu_confession`、`han_ledger_use`、`m11_conscript_proof`、`roster_accuracy`、`rc01_chen_yan`。
> **写入事实**：`truth_disclosure`（`1`=彻底公开, `2`=封存沉江, `3`=设愿知者名册）。
> **章末留下的问题**：真相已经定了调，接下来要强闯或绕过回澜关——谁愿意跟我一起去？

## 第一场：三十只粗陶酒碗、染血令箭与偏执狂的闭环

**【画面与 2D 宿命感演出】**
三更时分。回澜关信号钟楼底下的帅帐。
你和沈砾推开帐门时，外头那口带裂纹的铜钟正好敲响第一声。
**陆钧**背对着帐门（`Dir: Up`），面前的长案上没有摆沙盘，只整整齐齐摆着**三十只倒扣的粗陶酒碗**（`Prop: 30_Bowls_Inverted`）。他手里拿着花名册，声音不高，像平常训话一样往下念。

陆钧：第三旅工兵前哨，赵大锤。

（帐内死寂，无人应答。陆钧等了两秒，没有用笔划掉名字，而是伸手将第一只粗陶碗翻过来，倒上三钱烧刀子，`Anim: 陆钧_FlipBowl_Pour` + `SFX: Liquor_Pour`。）

陆钧：林小五。（等两秒，翻开第二只碗，倒酒）……沈砾。

**沈砾**（站在你身侧，手里的重型管钳“咚”地一声顿穿了帅帐的青砖地面，`SFX: Metal_Crack_Brick`，`Portrait: 沈砾_Fierce`）：老子还没死透呢！省下你那三钱猫尿！

陆钧倒酒的手在半空停住，却没有回头，稳稳把第三只碗倒满，才缓缓转过身来（`Dir: Down`）。
他从怀里贴肉的内袋摸出一支棱角已被摩挲得发亮、背面却染着黑褐色旧血的**木制三更令箭**，轻轻放在三十只酒碗正中央，同时摆出他救回来的**四百一十二人名册与借船欠条**（`Prop: 陆钧的蓝皮名册`）。

陆钧：那年冬月十七，三更令箭到我手里的时候，离水漫闸口还有两刻钟。我没有吹号通知桥对岸。

**【玩家操作：三轮甩账对质（将前期收集的证据作为弹药拍在案上）】**
玩家走近长案一格，在酒碗右侧并排铺开你一路收集的铁证（`Prop: 被没收船票的平民名单` + `SFX: Paper_Unfold`，镜头微推 `Camera Zoom: 1.2x`）：
1. **第一轮甩账**：出示 `M02`【迎水面四十五度工兵刀斜切断缆拓片】与 `RC-04`【死礁水文图】；
2. **第二轮甩账**：出示 `M11`【被副手强行没收船票的返乡平民名单】与 `RC-05`【八年前矿狱强征手令】；
3. **第三轮甩账**：若 `roster_accuracy == 0`（M10 对账准确率低），陆钧的军法官会当场挑出你名册上的“戌/戊”笔误反咬一口，你必须额外消耗韩峤人情或沈砾证词才能压住阵脚！

你（指着石案右半边的强征名单）：你救了四百一十二个人，可我现在看到的，是被你拆掉舵叶的民船、被收走船票的木匠，还有那些亲口说“不想再打仗”的人！

陆钧看都没看那张纸，猛地拔出佩刀，“夺”地一声插进长案木板里，眼眶通红，声音沙哑却带着一种病态的狂热（`Portrait: 陆钧_Fanatic_RedEyes`）。

陆钧：那是我下的命令！不是副手失控，是我的命令！

陆钧：你以为我晚上睡得着觉？！十二年前我在白水渡让人挥刀砍缆的时候，桥头还有十七个人在喊我的名字！——**桥这头，一万四千口；桥那头，一千一百人！**

> **【玩家选项：`[对话]` 刺破他的合理化闭环】**
> - `[“有人不想再打。他们只想回家种地、修椅子。”]`
> - `[“你上次在白水渡，也是拿算术题替所有人做决定的。”]`

陆钧（指着帐外翻涌的雾海，声音嘶哑得像裂钟）：如果你们今天脱了这身皮，回临潮去卖豆腐、修木椅、当个浑浑噩噩的顺民……**那十二年前死在桥下的那些弟兄算什么？！算我陆钧为了保官位杀的祭品吗？！**

陆钧：**不！只要你们跟我守住回澜关，只要第三旅的旗还插在这儿，那场仗就没有输！他们就是死在胜利前夜的功臣！你如果敢把“自家砍桥”的真相捅出去，你不是在毁我陆钧——你是在告诉那一千一百个死鬼，他们当年死得像条毫无价值的野狗！**

就在这时，钟楼顶上的铜钟正好响起报时的三声——第三声依然慢了半拍、沙哑破裂（`SFX: Bell_Toll_Cracked`）。
陆钧与你同时仰起头（`Sprite: Look_Up_Bell`），两人头顶同步浮现无边框浮字：`Flying Text: “一” → “二” → “三”`。

陆钧（手指按在那支染血的三更令箭上，声音突然低了下去）：你要杀我，等我把剩下二十七碗酒倒完；你不杀我，今晚回澜关的船，我照扣不误。

## 第二场：三方的难处与林素的回响

**【画面】**
对质之后，你回到关外临时据点。桌面摊开着三方势力的死结：
- **韩峤的难处**（若 M10 未入狱）：扩大军械检查会误伤普通返乡者，临潮粮路可能被东岸切断。
- **陆钧的难处**：武力能最快清掉押运威胁，但会立刻给东岸主战派重新动员的借口。
- **伊蕾的难处**：能监督合法移交，却管不住手里握着枪杆子的部队。

- `[条件（rc01_chen_yan >= 1）：若完成了名册案 RC-01]`
  陈砚的前妻**林素**随商船路过据点外，隔着门框看了你一眼，淡淡说了一句：**“你当初在芦花渡口是让我们知道，还是让我们安心——我是过来人。”**

## 第三场：交互式开门——三个人各自来找你（给“愿知者名册”装上倒刺）

**【玩家操作：房间内 3 个独立 `Interaction Machine`（拒绝站桩连续弹窗，由玩家亲自走过去对话）】**

1. **`[与门框边的沈砾对话（主张彻底公开）]`**
   沈砾靠在门框上，手里捏着半块修船粉笔：“他们本来就不是为了陆钧的旗死的！他们死是因为想回家吃饭！哪怕当野狗，也比给陆钧那个疯子当牌位强！……但我知道，你只要一公开，临潮的姜婶会第一个断了念想。我只是想你选的时候，什么都知道。”

2. **`[与桌边的姜婶对话（主张封存沉江）]`**
   老人特意从临潮托船赶来，双手死死按着铁匣盖子，眼泪砸在铜锁上：“沈家丫头，你没有白发人送黑发人！你要是把这匣子掀开，临潮东头陈嫂子今晚就会去跳井！我不是怕退钱，我是怕小豆长大了问我，她的英雄是谁。让我们带着那点念想入土，就这么难吗？！”

3. **`[与窗前的韩峤与伊蕾对话（主张设“愿知者名册”）]`**
   韩峤（或伊蕾）站在窗边：“我们可以把底稿和证词放进临潮祠堂，设一本‘愿知者名册’。愿意知道真相的家属自己签字来看；不愿意看的，不用知道。”
   沈砾（猛地转头怒斥）：“什么叫‘愿知者名册’？！把真相锁在黑屋子里，让活人像做贼一样去偷看？那桥底下泡着的人，死的时候可没得选！”

> **【角色路标（Signposting）】**
> 听完三人陈述后，桌上的油灯与底稿高亮。伊蕾合上怀表（`SFX: PocketWatch_Snap`）看着你：**“这一笔落下去，就没有反悔的余地。公开，今晚就有人信仰崩塌；沉江，你和沈砾查了一路的血证就成了哑巴；立愿知册，明天一早祠堂的门槛就会变成全镇人互相猜忌的刺。你来定规矩。”**

> **【玩家抉择：`[决定]` 渡口之夜的真相，怎么办？（写入 `truth_disclosure`）】**
>
> * `[决定 A · 彻底公开：敲响渡口钟，当众宣读三更断桥真相与假战报（truth_disclosure = 1）]`
>   你拿起底稿：“该让他们知道，亲人不是死在一句空洞的口号里。”
>   - **得与失**：死去的人不再替谎言背书，沈砾心结彻底解开（`shen_relation += 2`），大批不愿当祭品的旧部哗变脱离陆钧；**残酷代价**：遗属精神支柱崩塌，姜婶病倒，且船队中一名当年参与切缆的老工兵之子因不堪唾弃，在 M13 拔锚前夜离船投河（永久折损一名高级水手）。
>
> * `[决定 B · 封存沉江：将断桥实录锁入铁匣沉海，维持烈士碑文（truth_disclosure = 2）]`
>   你把底稿收进铁匣锁死：“活着的人还得靠这个故事撑下去。这笔脏账，我们知情的人自己背到入土。”
>   - **得与失**：遗属保住了安宁与抚恤，临潮镇民倾囊相助（M13 物资补给拉满）；**残酷代价**：沈砾认为你最终还是向谎言妥协，当场用扳手砸碎了桌角那张拓片（`shen_relation -= 2`，M15 点名时沈砾拒绝上台并站到人群最末排）。
>
> * `[决定 C · 设“愿知者名册”：存放在祠堂，仅对主动签字的家属开放（truth_disclosure = 3）]`
>   你把底稿递给伊蕾：“谁想问，就让他看见真话；不想问的，别去砸人家的门。”
>   - **得与失（打破中庸幻觉的“猜忌瘟疫”）**：表面兼顾双方，实则在 M13 清晨立刻引爆**“临潮祠堂猜忌内讧”**——去看过名册的家属看别人的眼神变了，不敢去看的家属整夜失眠怀疑自家死人是凶手；部分激进旧兵试图夜袭祠堂烧毁名册，伊蕾为了护住名册左臂被砸伤（M14 伊蕾支援效率 -20%），且你必须把底稿原件交出作为会盟桌上的把柄。
