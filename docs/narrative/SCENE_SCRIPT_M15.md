## 第一场：会盟桌外与“之后的一夜”

**【画面】**
镜湾会盟落幕。大厅里的条款还在签字，真正的生活发生在码头和空地上：卸船的木板吱呀作响，失散十二年的亲友抱在一起哭得喘不上气，工匠们围着招工告示打听工钱，医官在帐篷里替伤员换药。

**【之后的一夜（无任何任务标记）】**
船彻底靠岸的当夜，没有任务，没有战斗。

- **`[条件（crew_ayuan == 2）：如果阿鸢没能回来]`**
  码头上安静得可怕。祁雀的十几个船工并排坐在石阶上，谁也没有开口唱歌。**欧林**默默支起锅，煮了一大锅咸得发苦、很难吃的汤，盛给大家。没有人说好喝，也没有人说难吃，所有人端起碗，一声不吭地喝了个精光。
  祁雀坐在角落里，手里摩挲着那只印泥紫红的印章（`Portrait: 祁雀_Silent_Grief`），低声说：**“他校的舵偏左半格。我现在也没改。”**
- **`[条件（crew_ayuan < 2）：如果所有人都安全归来]`**
  码头上生起大火盆，船工们敲着空酒碗唱起走调的小曲，有人在大笑、拼酒，也有人躲在货箱后面偷偷抹眼泪。
