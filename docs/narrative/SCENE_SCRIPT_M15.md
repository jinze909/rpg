**夜里。回澜之后，船靠岸的当夜（没有任务标记）。**
- **`[条件：若阿鸢没能回来（crew_ayuan == 没能回来）]`**
  祁雀的船工们坐在码头上，没有人唱歌。**欧林**煮了一锅很难吃的汤，没人说，所有人都喝完了。
  **祁雀**坐在船边，低声说：**“他校的舵偏左半格。我现在也没改。”**
