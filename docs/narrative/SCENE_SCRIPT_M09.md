## 一、十八个铺位，二十三个名字

**白天。临潮船坞，祁雀的船舱。**
进入本章时，**第二则预兆**出现（`world_notices`）：**祁雀一位老友的货船在回澜关附近被军方“借用”了**，她没多说，但开始频繁查看海峡地图。

**M08 之后｜沈砾与欧林（仅沈砾仍参与时）：**
欧林：你又替谁答应了什么？
沈砾：没有。
欧林：那你手里怎么多了一张单子。
沈砾：……顺手接的。

船舱里，**床位表**摊在桌上：**第二批接驳默认十八个铺位、二十三个待安排的名字**，**不把 M07 已经安全离岛的三百人重复算作本船新上船者**。这是第二轮的基础案例，不是所有已完成名册案下固定不变的人数；先按实际登船意愿、已接出的人与已谈成的运力更新名单和缺口，未接出者不预占铺位。

（下列沈砾参与讨论和改船的对白，仅在 `shen_relation` 未明确决裂或退出时出现；若她已不同行，船舱由你、祁雀和欧林核对同一份名单，不借她的名义承诺。）
**沈砾**拿着铅笔，把小七的名字圈了又擦，擦了又圈。

你：旧部的第二批要先接，他们等得最久。

沈砾：蕊亚一家，我在赤盐时就答应了欧林。

你：你答应的时候，怎么没先跟我说？

沈砾：**我这不是在说吗？**

（话一出口，你们同时发现了一件事：两个人都在替别人安排，谁也没问过对方的名单。）
**祁雀**走过来，一把将铅笔从沈砾手里拿走：

祁雀：**吵完了？我的船只有十八张床。**

**沈砾与祁雀（改船·第一次；仅沈砾仍参与时）：**
沈砾：再塞一张床，我能把这条船改成八层。
祁雀：改成八层我就要收你升降机的钱。

## 二、三条换铺的路与变化

[操作：排布床位表（每个名字旁有年龄、伤、愿不愿意同舱；按实际待登船者与可用铺位核对，基础案例先安排十八张床；`RC-01` 至 `RC-05` 中确实愿意并需要乘船的人才追加到待安排名单，不把已留在当地或尚未找到的人算作已上船）]

默认案例缺五个铺位；名册案、登船意愿或已有运力改变时先重算实际缺口。以下三种交换各有代价，按需要组合或分批安排，不强制每次恰好增加五床：
1. `[找韩峤批民用航次：要你把名单上的人正式登记成活人]`
2. `[找沈砾认识的修船匠加铺：愿意换一次免费检修，条件是要沈砾留下教两天徒弟（信息留有备份，她暂时离队也不会卡死主线）]`
3. `[请祁雀让出一个载货航次：要你去和船工谈妥分成（若此前 `qi_debt_known == 否`，祁雀在此把船贷摊开）]`

按实际谈成的条件增加铺位或分批航次，重算待安排名单及运力（记录 `landing_capacity`）；未安排的名字仍待后续接应，不能算作已经登船。
**变化（仅沈砾仍参与时）：** 这一次，沈砾先去问蕊亚、问船工的意愿，才回来开口做承诺；你也向她说清了自己要什么。不是她哭着认错，也不是你认输（记录 `shen_relation`）。若她已明确不同行，不播放这段和解，不借本次运力谈判抹掉先前决定。

## 三、东岸渔村的接驳夜航

**夜。东岸渔村的小码头，浓雾。**
第二次接驳是一场夜航，海面上有巡逻船。

**夜航｜祁雀：**
祁雀：全船静音。现在谁的肚子叫，下一顿谁洗碗。

[操作：靠听雾避开巡逻船，在码头边用名字确认每一个上船的人]

**【蕊亚接驳结算（`survivor_ruiya`）】**
- `[接出蕊亚一家：本人愿意且能安排登船（survivor_ruiya = 接出）]`
- `[延后接应：当前接应条件不具备，继续保留待接名单（survivor_ruiya = 延后）]`
- `[本轮未接出：记录实际未接结果，不冒称她已登船（survivor_ruiya = 未接）]`

**仅当 `survivor_ruiya == 接出` 时**：欧林的妹妹**蕊亚**（东岸渔市账房）带着家人和账本上船。她脾气比欧林还冲，一上船看了眼航次费用表，就当面指出了你账上的错处：

蕊亚：这笔停靠费算重了两次。我对你们晏国人没成见也没感情，我只想知道，这趟船费到底谁来付？

此时，码头附近的芦苇荡边还停着一条**没挂旗的小艇**——是**陆钧的招募人**，正低声问上船的青壮愿不愿意“回队”。

**M09 之后｜沈砾与祁雀（第二次；仅沈砾仍参与时）：**
祁雀：床位表我划了十八条线。你每多一个名字，我就得删一碗饭。
沈砾：那我少吃。
祁雀：你少吃，我的船工就看着你吃。你觉得谁更难受？
