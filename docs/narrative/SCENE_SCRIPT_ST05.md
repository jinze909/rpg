# ST-05 · 两扇门的乔迁宴（地区与长期人物故事之五）

> **核心母题**：名字属于谁（十七号与十八号两块独立门牌，以及中间钉上的第三块《十七点五号院落公约》）。
> **开放窗口**：M02—M04 或 M10 镜湾居民街开放；M15 回访与小宴回响。
> **核心升级（推床变道物理喜剧 + 焦糖杏仁酥皮灭火拓出等高线 + 拆床搭阳光棚）**：
> 1. 告别居委会调解员式的口头劝架——让那张卡在楼梯天井里的雕花大双人床成为**实时改变房间通行路径与排烟风向的物理机关**！
> 2. 注入极佳的生活器物细节：程午压海图的镇纸是郁禾烤坏的硬法棍石头面包，郁禾切面团的刮板背面刻着程午的精密比例尺；
> 3. 升级晚宴冲突与幽默：烤炉火星燎焦了程午熬了十四天画的“黑鱼尾暗沙”海图，郁禾顺手拿一团焦糖杏仁酥皮拍上去灭火，竟意外在焦痕上拓出了完美匹配潮差的立体等高线！
> **出场人物**：你、郁禾（十八号面包师）、程午（十七号测绘绘图员）、热心姨妈与损友。
> **写入事实**：`st05_state`（`1`=保留两扇门并将大床拆改架在院顶当阳光棚, `2`=试住后一间合住一间改前店后画室）。

## 第一场：卡死天井的龙凤大床与渗透的器物

**【画面与环境叙事（Show, Don't Tell）】**
上午。镜湾西区老居民街，十七号与十八号相连的双层小院。
一张雕着俗气龙凤呈祥、比楼梯通道宽出半尺的**六尺红木大双人床**，正斜插在两间屋共用的楼梯天井转角处，左边床腿压着十七号门牌，右边床头顶着十八号排烟管，正中间铺着亲友硬塞的大红鸳鸯被（贺联上写着“程宅郁氏百年好合”，把两人的名字强行揉成一个符号）。

你观察小院地面，发现两人嘴上把边界分得清清楚楚，器物却早已密不可分：
- **十七号（二楼程午画室侧）**：青砖地面，晾着蓝晒海图纸，但**压海图纸的四个镇纸，全是用郁禾第一炉烤焦、硬得能砸核桃的法棍石头面包做的**；
- **十八号（一楼郁禾面包房侧）**：红砖地面，砖砌烤炉冒着果木香，但**郁禾切发酵面团的铜刮板背面，刻着程午亲手校准的精密毫米比例尺**！

此时，郁禾想去二楼拿发酵粉，必须从程午的绘图桌底下猫腰爬过去；程午想下楼交海图，必须踩着双人床的弹簧床垫翻窗跳进郁禾的面粉袋堆里！

## 第二场：推床变道机关与旧货市场的行家礼物

**【玩家操作 1：推拉旋转大双人床（实时改变路径与风向）】**
你在楼梯天井操作那张卡死的大床（可切换三个卡位角度）：
1. **往十八号压**：腾出二楼楼梯，但烤炉的热风顺着床板反射进十七号窗户，把程午刚画好的墨迹迅速吹干；
2. **往十七号压**：排烟顺畅，但挡死二楼画室正门；
3. **横架在天井正中**：大床直接变成连接十七号二楼窗台与十八号露台的**空中木廊桥**！

**【玩家操作 2：旧货市场淘选两份实用礼物】**
趁亲友散去喝茶，两人分别拉住你去旧货市场给对方挑礼物（最贵的镀金洋灯晃眼、大理石板遇热即裂，你通过实测挑中了**防风不晃眼的旧铜灯**与**透气不吸潮的青石散热板**）。

## 第三场：焦糖杏仁海图——晚宴上的爆笑火药桶！

**【画面与高张力喜剧交锋】**
傍晚，乔迁晚宴开席。突然一阵穿堂海风顺着斜插的大床缝隙灌进院子！
程午晾在架子上的《镜湾外海暗礁图》被吹落，直直飘进郁禾刚打开的烤炉口，“刺啦”一声燎着了右下角！郁禾眼疾手快，抓起手边刚出炉的一团**焦糖杏仁酥皮面团**，“啪”地按在图纸火苗上把火拍灭！

**程午**半截身子陷在双人床软垫里拔不出腿，手里高高举着那张右下角焦黑、还粘着一坨烤杏仁酥皮的海图，声音都在发颤（`Portrait: 程午_Shock_Tremble`）：

程午：郁禾！你管这叫“稍微串了一点点果木香”？！我画了十四天的“黑鱼尾暗沙”水深线，现在全变成你的焦糖杏仁海了！航务局的老头子要是照着这张图开船，船长到了礁石区是不是还得下锚先咬两口面饼？！

**郁禾**举着长柄木铲，鼻尖上沾着白面粉，仰头冲卡在床垫上的程午叉腰反击（`Portrait: 郁禾_Puff_Flour`）：

郁禾：那你去怪你三姑和二表舅啊！是谁听信他们说“两个人过日子非得睡一张六尺宽的龙凤床”？它现在一头顶着我的排烟口，一头压着你的楼梯板，我连给面团透气的门缝都被你们老程家的红木雕花堵死了！

郁禾：——再说了，你仔细瞅瞅我刚才拍灭火星子那团酥皮印子，是不是正好把你昨晚算不准的那道海沟潮差给填平了？！

程午愣了一下，凑近焦痕盯了三秒，默默从耳朵后面拔出炭笔，顺着杏仁酥皮的边缘画了两条等深线，耳根微红地嘴硬道：

程午：……比例尺偏了零点二毫米。不过看在这块酥皮救了暗沙等高线的份上，今年海图图例上的“高危浅滩”符号，我勉强用你的牛角包轮廓来画。
