# RC-03 · 白矶岛的多数（名册案之三）

> **名册上的一行**：白矶矿，已核验，二十七人，仍在营区。
> **开放窗口**：M08 之后开放，至 M10 会盟开幕前。
> **核心升级（暗码账本破译 + 蓝箬藏阀反转 + 好心办坏事陷阱）**：
> 1. **第一层假线索（Red Herring）**：二号淡水泵止回铜阀失踪、老会长带人收缴蓝箬船票，看似“多数人暴政强行绑架技术女工”；
> 2. **误判陷阱**：若直接拔刀强行带走蓝箬，三天后白矶岛因海水倒灌，7 名矽肺病老矿工集体渴死；
> 3. **第二层惊天反转**：玩家通过破译工器具暗码账本与打开蓝箬工具箱底层，发现**失踪的止回铜阀正是蓝箬自己偷偷拆下来藏进父亲遗像夹层里的**！因为全岛 23 个老矿工去年掏空棺材本替她还了父债、待她如亲闺女，她受不了这种“拿命对她好”的恩情债，说不出口“我想走”，才故意藏起铜阀想制造“全岛断水”的假象，逼 23 个老人不得不弃岛跟她一起上船！
> **出场人物**：你、沈砾、小七、罗会长（瑟兰断指老矿工）、蓝箬（晏国女技工）、重病矿工老秦。
> **读取事实**：`rescue_plan`（M06 是否选过 `3`=矿工停机配合）。
> **写入事实**：`rc03_baiji`（`1`=装回铜阀+小七教徒改会章, `2`=悄悄带走断水, `3`=留守一年, `4`=误信假线索强抢致死）。

## 第一场：第一层假线索——被锁死的泵房与收缴的船票

**【画面与 2D 演出】**
白天。赤盐群岛西北角的白矶岛。岸边挂着“互助食堂”和“夜校”的木牌，但岛上的气氛却紧绷得像拉满的弓。
干涸裂开的蓄水池边，断了两根手指的**罗会长**正带着几个矿工纠察队，把年轻女技工**蓝箬**堵在二号淡水泵房门口，强行收走了她手里的渡船票！

罗会长（把船票塞进兜里，看见你拿着名册走来，脸色铁青）：查册官？来得正好！二十七个晏国兄弟里，二十三个刚才按了手印自愿留岛！至于蓝箬丫头——二号淡水泵的核心止回铜阀昨晚被人偷拆了，泵修不好之前，按互助会章程，她哪儿也不准去！

- **【第一层表象（Red Herring）】**：看着缩在墙角眼圈通红的蓝箬，以及周围拿着铁锹围堵的矿工，你第一反应极易认定是**“罗会长故意藏起阀门，用会章绑架唯一懂修泵的蓝箬当免费苦力”**！

> **【误判陷阱（若不调查直接拔刀强抢）】**
> - 若玩家此时直接选择 `[决定：拔刀震慑罗会长，强行带蓝箬登船离岛（rc03_baiji = 4）]`：
>   你硬生生把蓝箬带上了船。然而离岛三天后（M09 前夕），白矶岛二号泵彻底报废、东井咸水倒灌，岛上老秦等 7 名重度矽肺病老矿工因无淡水熬药，集体肾衰死在礁石上！蓝箬得知死讯后在船舱里崩溃自残，与你彻底决裂！

## 第二场：暗码账本破译与工具箱底层的止回铜阀（4E 深度调查）

**【玩家操作：驻岛三联调查与暗码破译（Exploration & Experimentation）】**
你按住没有发作，在岛上住下查访三处核心线索：
1. **`[调查：互助食堂墙上的工器具暗码账本与病号房]`**
   为防鲁斯余党报复，互助会账本全用工具代号记名（你结合食堂领餐牌破译出：“三号风镐”=罗会长，“七寸铜阀”=蓝箬）。账本底下清楚记着：**去年冬天，岛上 19 个老矿工把全部安家费和棺材本凑出来，替“七寸铜阀（蓝箬）”还清了她父亲欠下的高利贷；罗会长更为了替她顶下废井背矿的差事，自己落下了晚期的烂肺病！**
2. **`[调查：二号淡水泵接口断裂痕]`**
   沈砾蹲下看了一眼阀门接口（`Anim: 沈砾_Inspect_Valve`）：“怪了。这止回铜阀根本不是被外行砸断的，是用专用内六角扳手顺着螺纹一圈圈卸下来的——全岛只有蓝箬自己有这把扳手。”
3. **`[调查：夜校下课后，检查蓝箬自己的工具箱底层夹层]`（真相大白！）**
   你在蓝箬工具箱最底层的父亲寻人启事夹层里，摸出了一块沉甸甸、用旧汗巾包得严严实实的黄铜件——**那枚失踪的二号泵核心止回铜阀，居然是蓝箬自己藏起来的！**

## 第三场：干涸蓄水池前的三方对质

**【画面与高张力对白重修】**
第二天清晨，二号淡水泵房前。重病矿工**老秦**嘴唇干裂渗血，抓着空水壶缩在墙根喘息。
**罗会长**剧烈咳嗽了两声，竟从怀里掏出一张连夜凑出来的十二两碎银票，塞进蓝箬手里，苦笑道（`Portrait: 罗会长_Weary_Kind`）：

罗会长：小箬，别跟查册官爷犟了。昨晚我想了一宿，二号泵的止回阀丢了，那是天意，不怪你。会里二十三个人刚才重新举手投过票了——废除会章第三条，豁免蓝箬的留守义务。趁今天渡船还没拔锚，你拿着这十二两碎银子，回大陆找你爹去吧。

老秦（抓着空水壶，低声嘟囔）：就是……二号泵一停，东井的咸水今晚就漫过来了。铁山哥，咱几个烂肺的撑不过五天……

罗会长（猛地回头瞪了老秦一眼，压低嗓子喝道）：闭嘴！接露水喝死不了人！当年老蓝头把闺女托付给咱们互助会的时候，咱们拍过胸脯的，不能让人家姑娘陪咱们这群半截入土的绝户死在礁石上！

> **【玩家操作：当众亮出止回铜阀】**
> 你上前一步，将那枚从蓝箬工具箱底层搜出来的**止回铜阀**拍在泵房铁台上，发出清脆的“铛”声（`SFX: Brass_Valve_Slam`）！

你：阀门没丢。它在你自己的工具箱底层，用你爹的旧汗巾包着。蓝箬，你想走没人拦你，但你不能用二十三条人命的活水，给你自己找一个心安理得离开的借口。

**蓝箬**脸色煞白，扑通一声跪倒在铁台前（`Sprite: 蓝箬_Kneel_Cry`），双手死死抓着头发崩溃哭喊：

蓝箬：**我不藏起来我怎么走得掉啊？！罗叔！你们要是拿鞭子抽我、要是拿会章捆着我不放，我半夜偷条舢板早就划走了！**

蓝箬：**可你们每天把最后半瓢淡水留给我洗脸，老秦叔咳成那样还替我擦扳手……我每次刚张嘴想说“我想去找我爹”，你们就握着我的手说“咱们都说好了共渡难关”！我要是修好了泵拍拍屁股走了，我这辈子每喝一口水都会看见你们死在岛上！我只是想逼你们觉得这岛没救了，好跟我一起走啊！**

## 第四场：三种解法与主线联动

> **【角色路标（Signposting）】**
> 沈砾拿起那枚止回铜阀看着你：“阀门现在装回去，水马上能通。但人是留、是走、还是找人替她教出接班的学徒，你来定。”

> **【玩家抉择：`[决定]` 白矶岛与蓝箬的出路（写入 `rc03_baiji`）】**
>
> * `[决定 A · 装回铜阀 + 技术破局改会章：拿出简化修泵图，让小七留岛七天教会三个接班学徒（rc03_baiji = 1）]`
>   - `[条件加成：若 M06 选过 rescue_plan == 3（矿工停机配合）]` 你直接掏出沈砾当时画好的备用简化阀图纸；**小七**主动往前站了一步：“师傅教过我这一型的阀！我留岛七天，包教包会三个人！”
>   - **代价与结果**：在岛上多耗一周工时，小七累哑了嗓子教会三个学徒。二号泵水压恢复，罗会长心服口服修改会章，蓝箬堂堂正正登船（**M09 床位表增加蓝箬；M14 获得白矶岛淡水暗渠与矿工爆破组强力支援，即为阿鸢生还汇聚锁 Key 3 之一**）。
>
> * `[决定 B · 装回铜阀，但由沈砾暂时留岛代守：放蓝箬立刻乘船寻父（rc03_baiji = 2）]`
>   - **代价与结果**：白矶岛水源与蓝箬寻父同时保全；**硬核代价**：沈砾必须留在白矶岛替她带徒弟，导致你在接下来的部分支线或筹备中暂时失去沈砾同行！
>
> * `[决定 C · 劝蓝箬装回铜阀并按原会章留守一年：你替她回大陆查父下落（rc03_baiji = 3）]`
>   - **代价与结果**：蓝箬擦干眼泪，亲自拿起扳手把止回铜阀装回二号泵：“……我留一年。一年内我把老秦叔他们都教会。”你接过她的寻父信替她在大陆查实父亲下落。

**【M15 终局点名回响】**
点名册翻到“白矶岛互助会二十七人”时：
- 若选 A：蓝箬在台下响亮地答“在！”，罗会长托人送来《会章修订本》并高举止回铜阀拓片：“二十三人留守礁盘供水，四人随船护航——二号泵水压正常！”
- 若选 C：信使递上一张从白矶岛寄来的空白回执单，背面写着：**“还有十一个月。水很甜。”**
