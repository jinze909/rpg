## 一、伙伴场：每个人的底线与回答

**傍晚。出发前的船坞。**
在进入回澜关终局之前，**实际愿意到场**的同伴围坐在一起，把各自愿负责的部分与底线说清楚；退出或翻脸的人不因这一幕被强行召回：

**若沈砾仍愿同行**，她整理工具袋，说：旧运渠的水闸和关内的机械交给我。我把话说在前面：我之后想留着工坊的计划，而且我不接受拿工匠和伤员去填路的命令。
**若 `shen_relation` 已决裂或她明确不同行**，本段不由沈砾发言，也不以其名义接下机械任务；回澜的机械难题依原定替代方案，由已结识的船工、当地修船铺或付费拖船承担，代价落在资源和战术上。

**若祁雀仍同意带船且在场**，她拿着船工名册：船工们商量过了，愿意跟你跑这一趟。但我的船负荷有上限，哪条水道能进、哪条不能硬闯，得按我的吃水线来。**若她已经拒航或不在场**，由已联系的租船船长、合法移交船队或中立承运人提供真实报价与吃水线；不能借她之口答应未同意的船工，也不失去保底通路。

**仅欧林同意参与且实际到场时**，他擦着开锁工具：我代表自愿跟来的工匠与家属出力，不替全体东岸人发言。若 `survivor_ruiya == 接出`，他再说：“干完这一场，我要带蕊亚回家吃饭。”若仍为“延后／未接”，他不宣称团圆，只谈以后落实的接应。**若欧林不参战或未到场**，这几句都不播放，改用已落实的替代工匠方案；救人善意不自动等于参战承诺。

**小七与陶霁分别按已接出、本人愿意且实际到场判断**：小七在场便检查备用手摇泵；沈砾仍同行时他才说：“师傅去哪儿修水闸，我就去哪儿递扳手！”陶霁在场才加固舵榫、码齐备用木楔。缺席者的工作由已确认船工替代，不能把 M07 获救等同于 M13 必然在场，更不能替已离队的沈砾预先安排修闸。

## 二、六项准备检查与阿鸢的风险预警

[操作：在海图桌前逐项核对六项准备（写入 `landing_capacity`）]

1. **泊位**：核对镜湾与临潮的停靠泊位（受 `han_ledger_use` 影响）；
2. **关内接应或替代路线**：核对旧运渠、钟楼与广场通道（受 `RC-01`–`RC-05` 及 `ST-01`–`ST-06` 影响）；
3. **被接出者去处**：核对安置点与分批计划（受 `survivor_ruiya`、`survivor_liang` 影响）；
4. **具体供给**：核对 M10 合同是否签妥、覆盖哪些人及粮何时到。尚未签妥时先落实分批补给或借粮，已断的山路粮线另记缺口；
5. **盟友的条件**：伊蕾、韩峤确实到场并愿承担时才与本人核对；否则检查确已送达的监察副本、商会港务担保与实际替代人员，不让离队者隔空签约；
6. **姜婶的那笔账**：核对 `pension_path` 在补偿账上留下的数字。
（所有项目都有最低可行方案：借贷、分批、额外行动或牺牲某项便利；没完成的支线不会封锁主线。）

**【风险与警告】**
核对路线 B 的信号绳与路线 C 的运渠口闸时，**实际带队的船长**发出明确警告：若祁雀带队，由她说：“这两处，我的人里会有人回不来”；若她拒航，则由已落实的替代船长说明同一风险，不能伪造祁雀的同意。

**只有阿鸢本人实际在队、知情并主动请缨**，才写入 `crew_ayuan_assignment = 本人自愿值守`；否则由已落实安全接应的替代班组承担（`已落实替代班组`），不能把他强行送去危险岗位，也不新增他人的永久死亡。替代人员和安全接应未落实则 `未落实`，B/C 暂不可启程。

**M14 之前｜阿鸢与祁雀**（只有二人都在队里时）：
阿鸢：这趟回来我要把第三段唱完。
祁雀：你上次也这么说。

[“把人手和接应船排好。谁守那个位置，咱们都要把人接回来。”]（只有六项准备确实落实到 `landing_capacity`，且人手、替代通路、接应均可用，才写入 `crew_ayuan_risk_acceptance = 已补齐准备`。）
[“先回港补齐准备再出发。”]（暂缓启程；尚未实际补齐前仍记 `crew_ayuan_risk_acceptance = 未确认`，不能把计划当作已完成。）

**【准备不足而仍想走路线 B／C 时的独立确认】**
只有听完实际带队船长的明确警告、`crew_ayuan_assignment = 本人自愿值守`、仍缺少安全接应，才能出现以下二选一；只选择路线 B／C 不算已经接受永久失去同伴的风险：
- `[暂缓启程，补齐人手与替代接应，让阿鸢安全回来（crew_ayuan_risk_acceptance = 未确认；补齐并复核前不得启程 B/C）]`
- `[我听明白了风险；准备仍不足，但坚持由阿鸢值守，接受他可能重伤退出或没能回来的后果（crew_ayuan_risk_acceptance = 准备不足但明确接受）]`

若没有选第二项且准备仍不足，**路线 B／C 的确认启程暂不可用**，`crew_ayuan_risk_acceptance` 保持 `未确认`：必须先真实补齐接应并复核，或换路线 A；不能一边让阿鸢去无接应的位置、一边凭默认值假装他安全。只有阿鸢自愿值守且玩家独立明确风险选择才写入 `准备不足但明确接受`，M14 才可能结算他重伤或永久离开；战斗失败重试不视作叙事风险确认。

## 三、推进确认

实际带队的船长（祁雀带队时由她说）：确认启程以后，回澜关就进入封航阶段了。已经联络、确实愿意寄出的消息，之后可能走尾声信件；**未开启的地区线和未查到的人只能记为暂缓或下落待查，不会凭空寄来完成通知**。你想好了，我们就拔锚。

> **【玩家抉择：确认进场路线并启程】**
> - `[暂缓启程，先去完成未做的地区回访或收尾安排]`
> - `[确认启程：走路线 A（监督移交与民用通路）；阿鸢不进入 B/C 高风险哨位，写入 crew_ayuan_risk_acceptance = 路线A不进入高风险哨位]`
> - `[确认启程：走路线 B（夜里夺钟楼，武力打开归途）；除阿鸢风险门禁外，须确认三声钟“开门”反号已通知船队和关内接应（纳入 landing_capacity）]`
> - `[确认启程：走路线 C（旧运渠夜航，中立安置与绕行）；同样仅当 crew_ayuan_risk_acceptance = 已补齐准备 或 准备不足但明确接受时可启程]`
> （B/C 若仍为 `未确认`，选项保持锁定；回到准备桌完成实际补给、替代通路与接应，或改走 A。不能通过重复点击路线来替代风险确认。）
>
> **【路线写入与回退规则】** B/C 若由阿鸢本人自愿值守，必须通过“已补齐准备”或“准备不足但明确接受”的风险门禁；若由替代班组执行，仍需真实落实安全接应，只能写“已补齐准备”，不能让玩家替陌生班组接受不可逆损失。B 还必须将三声钟“开门”反号实际告知船队及关内接应，不得在 M14 临时假设大家早已知道。暂缓启程不写入胜利；只有路线经上述门禁确认并实际启程时写入 `final_route_choice = A 监督移交 / B 武力通路 / C 中立绕行`。这是**进场计划**，不是主结局。M14 若路线实际受阻，先展示可承担的补救（证人、港务担保、分批运力或局部行动）；需要改 A/B/C 时由玩家明确重选并返回本章复核准备、阿鸢同意与航次成本，不在失败画面里暗改选项。若阿鸢已经重伤或没能回来，他的去向和已付代价随队带回；重选 B/C 只能重新落实安全替代班组。
