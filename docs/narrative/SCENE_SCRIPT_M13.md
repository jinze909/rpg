## 第一场：清晨祠堂门外的露水（M12 真相抉择的即时回响）

**【画面与 2D 分支变体演出】**
天刚蒙蒙亮。回澜关外十里的避风海湾与临潮联络栈桥笼罩在寒雾中。
根据你在 **M12 第三场** 拍板的 `truth_disclosure`，清晨第一幕呈现截然不同的创伤现场：

- **`[条件 A：若 M12 选择了“设愿知者名册”（truth_disclosure == 3）]`**
  祠堂与联络站台阶下撒着昨晚内讧争抢时撕碎的纸页。**伊蕾**托着缠满渗血布条的左臂靠在门框上（`Portrait: 伊蕾_Injured`）；**姜婶**站在十步外的寒雾里，鞋尖全被露水打湿了。
  你走过去：“姜婶？你在这儿站了一宿……进去看过了？”
  姜婶（摇了摇头，声音哑得像砂纸磨木头）：**“我走到门槛边，看见老陈家的媳妇哭着跑出来，看见我的时候，像见了鬼一样绕着墙根走……我不敢迈进去。孩子，你给了婶子一个选法，可从昨晚起，这镇上的人连抬头看彼此一眼都不敢了。”**
- **`[条件 B：若 M12 选择了“彻底公开”（truth_disclosure == 1）]`**
  码头边围着一圈沉默的水手——当年参与三更切缆的老工兵之子，昨晚把父亲的抚恤银袋退在甲板上，跳海自尽了。**沈砾**独自站在船头加固缆绳，眼眶通红却一言不发。
- **`[条件 C：若 M12 选择了“封存沉江”（truth_disclosure == 2）]`**
  镇民们送来了满满三车御寒棉衣和干粮，但**沈砾**坐在远处的礁石上擦扳手，看见你走近，直接背过身去（`Dir: Turn_Away`），只公事公办地谈机械参数。

## 第二场：伙伴表态与“冷锻铁叶”战位分配（阿鸢生还汇聚锁 Key 2）

**【画面】**
船舱里点着马灯，核心伙伴围坐在甲板木箱旁，各自亮出底线：
- **沈砾**（清点扳手与撬棍）：“运渠的水闸、关内的机械暗门归我。但我把话说死——我不接受‘把工匠当炮灰填进去’的命令。谁要这么干，我当场卸舵。”
- **祁雀**（转着那枚印泥红得发紫的“雀行”商号印章，看了一眼船尾擦弦的阿鸢）：“我的船最多吃水到这个刻度。明天不管是走正门还是钻运渠，需要有人留下来守高危位置的话，**得提前把防箭挡板和接应备足，别拿我的人去赌运气。**”
- **欧林**：“我只代表自愿跟着来的十几个工匠和东岸渔家说话，不代表整个东岸。干完这一票，我得带蕊亚回家吃顿热饭。”
- **小七**（握紧扳手站在沈砾身后半步）：“我跟师傅学过拆水闸，我能拧得动三号螺母。”

**【玩家操作：六项清点与“北岭冷锻铁叶”关键分配（写入 `m13_stern_shield`）】**
海图与整备表摊在木箱上，玩家逐一核对六项准备（泊位、关内路线、安置点、供给合同、盟友条件、姜婶账目），并面临一项决定 **M14 阿鸢生死** 的核心工程分配：
- 木匠**陶霁**（若已完成 `ST-06` 则自带精良木榫加成）指着船尾副舵位对你说：“船坞里只剩最后一批**北岭冷锻铁叶**，只够改装一处——要么拿去加固船头撞角与主战兵器，要么拿去给**船尾副舵加装三层防箭挡板**。”

> **【玩家抉择：`[决定]` 冷锻铁叶的用途（汇聚锁 Key 2）】**
> - `[决定 A · 加固船尾副舵防箭挡板（写入 m13_stern_shield = true）]`
>   你：“船尾副舵是过旧运渠铁栅的死穴，把冷锻铁叶全包在副舵护栏上！”（获得阿鸢生还汇聚锁 **Key 2**！）
