## 一、伙伴场：每个人的底线与回答

**傍晚。出发前的船坞。**
在进入回澜关终局之前，**实际愿意到场**的同伴围坐在一起，把各自愿负责的部分与底线说清楚；退出或翻脸的人不因这一幕被强行召回：

**若沈砾仍愿同行**，她整理工具袋，说：旧运渠的水闸和关内的机械交给我。我把话说在前面：我之后想留着工坊的计划，而且我不接受拿工匠和伤员去填路的命令。
**若 `shen_relation` 已决裂或她明确不同行**，本段不由沈砾发言，也不以其名义接下机械任务；回澜的机械难题依原定替代方案，由已结识的船工、当地修船铺或付费拖船承担，代价落在资源和战术上。

**祁雀**（拿着船工名册）：船工们商量过了，愿意跟你跑这一趟。但我的船负荷有上限，哪条水道能进、哪条不能硬闯，得按我的吃水线来。

**欧林**（擦着开锁工具）：我代表自愿跟来的工匠与家属出力，不替全体东岸人发言。（若 `survivor_ruiya == 接出`，他说：“干完这一场，我要带蕊亚回家吃饭。”若仍为“延后／未接”，他不宣称已团圆，继续保留接应她的安排。）

**小七**与**陶霁**正在船尾加固舵榫与备用手摇泵。若沈砾仍同行，小七拍了拍工具袋：“师傅去哪儿修水闸，我就去哪儿递扳手！”陶霁点了点头，把备用的木楔码齐在舱板上；若沈砾已明确不同行，小七仍能参与加固，但不预告她要亲自修水闸。

[“我明白。这一趟，我需要你们在水道、船只和关内接应上帮我。”]
[“要是有高风险的位置，我们提前把替补和退路排好，不硬填人命。”]

## 二、六项准备检查与阿鸢的风险预警

[操作：在海图桌前逐项核对六项准备（写入 `landing_capacity`）]

1. **泊位**：核对镜湾与临潮的停靠泊位（受 `han_ledger_use` 影响）；
2. **关内接应或替代路线**：核对旧运渠、钟楼与广场通道（受 `RC-01`–`RC-05` 及 `ST-01`–`ST-06` 影响）；
3. **被接出者去处**：核对安置点与分批计划（受 `survivor_ruiya`、`survivor_liang` 影响）；
4. **具体供给**：核对 M10 签下的供给合同；
5. **盟友的条件**：与到场的**伊蕾**、**韩峤**核对监察副本、港务担保与旧部意向；
6. **姜婶的那笔账**：核对 `pension_path` 在补偿账上留下的数字。
（所有项目都有最低可行方案：借贷、分批、额外行动或牺牲某项便利；没完成的支线不会封锁主线。）

**【风险与警告】**
核对路线 B 的信号绳与路线 C 的运渠口闸时，**祁雀**指着这两处必守的位置，提前对你说清：

祁雀：**这两处，我的人里会有人回不来。**（准备不足时，阿鸢可能重伤退出，也可能没能回来；不是必然死亡。）

舵手**阿鸢**走上前，主动请缨去守那个位置。

**M14 之前｜阿鸢与祁雀**（阿鸢在队里时）：
阿鸢：这趟回来我要把第三段唱完。
祁雀：你上次也这么说。

[“把人手、替代通路和事先布置的接应全投进去，我要阿鸢活着回来。”]
[“先回港补齐准备再出发。”]

**【准备不足而仍想走路线 B／C 时的独立确认】**
只有已听完祁雀明确警告、仍缺少安全接应且准备派阿鸢值守，才能出现以下二选一；只选择路线 B／C 不算已经接受永久失去同伴的风险：
- `[暂缓启程，补齐人手与替代接应，让阿鸢安全回来]`
- `[我听明白了风险；准备仍不足，但坚持由阿鸢值守，接受他可能重伤退出或没能回来的后果]`

若没有选第二项，`M14` 不得结算阿鸢永久离开；战斗失败重试不视作叙事风险确认。
