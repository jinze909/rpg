## 一、纪念日广场与高台小戏

**白天。临潮港。** 海风里有人叫卖“英雄糖人”。孩子们排着队，摸石碑上刻的字，那一块已经摸得发亮。
碑前有一位老妇人在用袖子擦另一个名字，有人挡到她，她就侧一下身，没抬头。人群边缘有两个穿旧军服的人（袖口缝着蓝布），一直在看你。

[操作：走近石碑，看上面刻着的你的名字与雕像]

（石碑上刻着：“敌军火攻浮桥，第三旅死守桥头，全员殉国。”）

**第一次看见雕像时，可选的反应：**
[“鼻子雕得太直了。”]
[“谁给挑的披风？我那会儿连被子都没有。”]
[“拆了吧。”]
[“这钱是谁捐的？”]

[操作：观察碑前用袖子擦字的老妇人（记录 `old_woman_stone = 已触发`）]

（她擦的名字是“第三旅一营三班·郝烈”。有人挤过来，她不争，只往旁边让了半步，等那人走了又继续擦。）

**台上，一个十岁的孩子穿着太长的军服。**

小豆（台词，背得很响）：桥在我在！

（你站在人群后面。你记得的不是这句话。）

## 二、第十二年的点名

**碑前。** **韩峤**站在石碑下，手里拿着一份名单。他比十二年前瘦，官服上缝过一道补丁。

韩峤：第三旅，旅正以下一千一百人。每年念一页，十二年，今天是最后一页。**名字还是照旧念法，最多三遍。有人应，就停。**请诸位静一静。

（广场小戏散场后，碑前开始正式点名。场景切到稍后，韩峤已经念过本页大半，只剩最后几个名字。玩家从这几行听起。）

韩峤：……

（这个名字念了三遍，始终无人答。韩峤用指腹压住纸角，往下念。这里是年祭，名册上的旧登记须另到官署核定。）

韩峤：……

（韩峤念到你的名字。**每一遍都是独立的呼名与回应窗口；一旦你应声，立即停止，不再念下一遍。**）

**第一遍。**

韩峤：（你的名字。）

[应声：“在。”]（立即记录 `identity_reveal = 应声第1遍`，停止后续呼名）
[继续沉默]
[离开人群]（记录 `identity_reveal = 离开人群`；你离开后，韩峤仍把名字念满三遍，三遍无人应）

**只有第一遍无人应、你仍留在人群时，才进入第二遍。**

韩峤：（你的名字。）

[应声：“在。”]（立即记录 `identity_reveal = 应声第2遍`，停止后续呼名）
[继续沉默]
[离开人群]（记录 `identity_reveal = 离开人群`；之后的呼名无人应）

**只有前两遍都无人应、你仍留在人群时，才进入第三遍。**

韩峤：（你的名字。）

[应声：“在。”]（记录 `identity_reveal = 应声第3遍`）
[沉默]（记录 `identity_reveal = 沉默`）
[离开人群]（记录 `identity_reveal = 离开人群`）

**如果你在任一遍应声。** 人群回头。韩峤在你应声的那一遍后立即抬头，停了三秒，慢慢合上那一页；如果你等到第三遍才答，他合上名单时，手在抖。此后不再呼你的名字。

韩峤（对台下）：今天的名单念到这里。各位请自便。

韩峤（低声，对侍从）：把那位请到后面去。

**如果三遍都没有回应（包括你离开人群）。** 他念完第三遍才合上名单；若你仍在场，目光在人群里找到你，若你已离开，他看见你离去的方向。他同样让人去巷口把你请到后面。

## 三、石碑后的小屋与“四十一个”

**后面。** 石碑后的小屋，窗外是海。刚才人群里那两个穿旧军服的人远远看了小屋一眼，转身离开。
小桌上摆着刚端来的热饭菜和两副碗筷。窗外就是刻着你死讯的石碑。韩峤把一副筷子摆到你面前。

韩峤（指了指桌对面的座位）：坐下吃口热饭吧。……你没死。

[“战报上写我死了。”]
[“你认出我了。”]
[“沈砾呢？”]

（他认了活人，没有认战报。）

韩峤：我知道还有人活着。我接回过一些。

你：多少？

韩峤：四十一个。从停战到现在。

（他说得很快，像在算粮。记录 `han_ransom_count = 41`。）

（若你先前问过沈砾，你把筷子放下：“那四十一个人里，有她吗？”否则问：“沈砾呢？”）

韩峤：不在我手里的名单里。（停）前些天赤盐传回消息，矿主鲁斯在镜湾会盟前调动劳力，要把人拆散转运。你想让我去查，还是先想办法弄一条船？

[“战报说桥被敌军烧了。可我记得，桥是先断的。”]
[“先弄船。我要去赤盐。”]

韩峤（停了一拍）：船的事，明天来港务署谈。你今晚先去西巷看一眼姜婶——十二年前你留的紧急联系人是她，抚恤一直发在她手里。

（韩峤起身去倒茶。桌上，他的赎俘账册摊开着。最后一页，你的名字被墨涂过，涂了又写，写了又涂。）

**镜头停在那一页。**
