# 《归来》验证计划 v1.2

“归来”为工作标题。本文回答一个问题：在大规模制作之前，怎么知道这个故事能不能吸引玩家。这是建议流程，不是已经做过的测试。数字门槛是我给的参考值，不是业界标准。依据见 [NARRATIVE_GUIDE.md](NARRATIVE_GUIDE.md) 第八节。

## 原则

- 先验证“承诺”（玩家知不知道这是什么），再验证“手感”（玩得下去吗），最后验证“留存”（想不想继续）。成本从一晚到几周，每一步都先于下一步。
- 三到五个人只能得到定性的东西，别用百分比安慰自己。
- 不问“好不好玩”，问他们做了什么、记得什么、最想知道什么。

## 测试一：一句话测试（一晚）

把一句话念给三个没听过的人，让他们复述这是什么游戏，不讲设定。候选三句：

- A 概念：战死是一道公文。盖了章，人就不存在了。你回来，是要把他们一个个从死人名册上领回来。
- B 仪式：他们说你们死了。你回来点名。
- C 场景：石头上写着你是怎么死的。写下它的人，现在请你吃饭。

通过：至少三个人里两个能说出“主角被登记成死人，要去把别人救回来”。不通过：先改概念，不要只改措辞。

## 测试二：商店页与预告片（两三天）

做胶囊图（缩到很小仍能读出是什么）、三百字以内的简介、预告片分镜（见 PITCH_AND_HOOK.md 第四节）。给陌生人看十秒，问：这是什么游戏？你会不会加愿望单？为什么？

参考做法：预告片的钩放在前十秒。另有第三方整理引用 Chris Zukowski 2025 年 2 月的调查，说愿望单大多来自只看了商店页就点下按钮的人，而不是玩过试玩的人，所以商店页要单独验证。这条是转引，我没有核实原始数据。

## 测试三：文字原型（P0 加 M00 加 M01，约 20 分钟）

用浏览器页面、Ink 或 Twine 做纯文字版。保留：点名时怎么答、扳手的外号、沈砾的工坊梦想三种回答、拉人三次、钟声数到三、缆崩开、纪念日碑前点名、韩峤那句“四十一个”、账册最后一页、姜婶的铁盒。结尾停在“战报说桥被敌军烧了，可你记得桥是先断的”。

记录：

- 有没有读到最后。
- 点名时选了什么（应声、沉默、退出），以及应声发生在第几遍。三个选项都有人选，才说明选项成立。
- 结束后问：沈砾是谁？桥出了什么事？战报哪里不对？你最想知道什么？想继续吗？为什么？

参考门槛：五个人里至少四个读到最后；至少三个人提出的问题落在预设的悬念上（桥是谁断的、战报谁写的、沈砾还活着吗）；至少三个人想继续。

提醒：一些学生项目的测试报告里，常见情况是测试者不读完整文本、对界面感到困惑、觉得选择没分量。第一次测试把界面做得最简单，每屏文字压短。

## 测试四：朗读会（半天）

用 [SCENE_SCRIPT_P0.md](SCENE_SCRIPT_P0.md)、[SCENE_SCRIPT_M00.md](SCENE_SCRIPT_M00.md)、[SCENE_SCRIPT_M03.md](SCENE_SCRIPT_M03.md)、[SCENE_SCRIPT_M12.md](SCENE_SCRIPT_M12.md)、[SCENE_SCRIPT_RC02.md](SCENE_SCRIPT_RC02.md) 和 [SCENE_SCRIPT_ST06.md](SCENE_SCRIPT_ST06.md)（及全套 29 份单章剧本），找三到五个人轮流读，记录哪里笑了、哪里静了、哪里有人想打断。

**验收边界**：目前只校验剧情文本的输入、写入与后续读取，不声称这些变量、NPC、UI 和全部分支已被 Unity/ORK 实现。实际可玩时须用同一最终候选 SHA 的工程验证、状态存档往返和逐分支测试补证据；没有证据的行仍记“待验证”，不报“已通过”。

## 测试五：试玩版（有玩法之后）

建议的切片：P0，M00，M01，M02 调查缆口，M03 陆钧说“我知道桥三更断，我没说”。终点定在 M03 的悬念。有开发者报道，悬念结尾的 demo，愿望单转化比“完整体验”结尾高（转引自第三方整理，没有核实）。

## 结果怎么用

| 现象 | 可能原因 | 对策 |
| --- | --- | --- |
| 复述不出来 | 概念不清 | 改概念，用 A/B/C 里复述得最好的一句 |
| 读不下去 | 文字太长，缺少操作 | 压缩 P0 文本，增加操作 |
| 点名没人选“应声” | 玩家没把主角当自己 | 强化 P0 里与沈砾的关系，让“被叫到”更有分量 |
| 悬念不集中 | 谜线埋得不清楚 | 把战报与断桥的矛盾提前一屏 |
| 只想继续玩沈砾，不在乎谜线 | 谜线不够个人 | 把谜线和沈砾绑得更紧（她看过缆口） |

## 成本与顺序

测试一一晚，测试二两三天，测试三两三天，测试四半天，测试五取决于玩法。前三个都不需要引擎。如果文字原型没通过，不要往下做。
