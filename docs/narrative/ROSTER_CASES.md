# 名册案：名册上的五行空白 v1.2

“归来”为工作标题。本文是可改的写作基线，不代表已实现内容，具体玩法形式待玩法侧评估。

**它们是什么。** 赤盐营救取得的转运名册里，除了已经领回的人，还有五行没有结果。每一行是一个独立的小故事，写法照《巫师3》的委托：一行字起头，查，揭，选，几章后在别处撞见后果，最后以点名收束。

**什么时候做。** M08 之后开放，到 M10 的会盟开幕前。顺序自选，做几条都行，没有强制。每做完一条，M09 的床位表上多几个名字，M10 的核验谈判多一份证据或证人，M15 的点名里多一张脸；没做的，会在点名时被念到“下次”。每条估 1 到 2 小时。

**共同规则。** 每条至少两方当事人各有道理，戏份相当；选择前能看到一半代价，另一半事后撞见；没有一个选项能把所有人都救了。每条都有一个种子（在前面章节里埋过）和一个回响（在后面章节里撞见）。

## RC-01｜砚叔的两个家

（已写出可朗读的场景稿：[SCENE_SCRIPT_RC01.md](SCENE_SCRIPT_RC01.md)。）

**名册上的一行。** 陈砚，第三旅炊事兵，下落待查。

**起头。** 白苇平原的渡口有个摆渡人，人人叫他砚叔。他会烙一种葱油饼，面里掺炒过的盐，和第三旅炊事班的做法一样。他说自己从没当过兵，只会烙饼。

**查。** 你在渡口住几天，帮他撑船、跑腿。线索都很小：左手腕一道烫疤；收饼时他哼过半句只有炊事班才会唱的调子；渡口边小祠里有一块没有字的牌位，他每月初一去上香。镇上人说他八年前从下游走来，一个人，后来娶了秋娘，生了阿河。

**揭。** 他是停战后逃出营区的。一路走回临潮，在城门外看见妻子林素挽着另一个男人，牵着女儿陈婉从集上回来。林素合法改嫁，因为他被登记战死。他没有敲门，沿河走了三个月，到渡口落脚。那块无字牌位是他给自己立的。

林素其实在人群里认出了他，没有喊住他。她后来对你说：“他走得很稳。我那时候想，他是想好了的。我就没喊。”这件事她藏了八年。

**选。** 他听你的，自己不提任何要求。
- **恢复“在世”。** 第一段婚姻在法理上恢复，林素的再婚作废，抚恤须追缴，陈婉的婚事受牵连；他与秋娘的婚姻同样无效，阿河成了无籍的孩子。
- **保持“战死”。** 两个家继续各自完整，但他永远不能用本名出现。点名那天，他不能答。
- **新名字。** 伊蕾或韩峤可以给他一个“归还者”的新登记，两边的现状都不被推翻，但“陈砚”这个人在法律上永远死了，陈婉再也不能认他是父亲。

林素和秋娘各自陈述，戏份相当。你先找谁谈，会改变谈话的气氛。

**回响。** M12 时，林素会提起你当时的选择：“你让他们知道，还是让他们安心，我是过来人。”M15 点名：恢复在世，他在人群后答“在”，两个家第一次站在同一块地上；新名字，念的是新名字，他答了，看了林素一眼；战死，念到陈砚无人答，渡口那边有人摇了一下船铃。

## RC-02｜借来的名字

（已写出可朗读的场景稿：[SCENE_SCRIPT_RC02.md](SCENE_SCRIPT_RC02.md)。）

**名册上的一行。** 郑沅，第三旅斥候，母亲在世，下落待查。

**起头。** 镜湾接纳处，一个自称郑沅的人带着一位老妇人来登记“归还者”。伊蕾卡在核验上：牙对不上，口音有点偏瑟兰。老妇人拄着拐站在他旁边，一言不发。

**查。** 你陪伊蕾核验：讲斥候时期的事，他把一场伏击的方向说反了；问老妇人儿子的小习惯，她说“左手拿筷子”，而此人用右手。你去他住的棚屋，屋顶是新修的，修了三次。

**揭。** 他叫石棱，瑟兰与晏国的混血债工，欠着一笔永远还不完的债。他在矿营听说名册上有人名字还在、人却不在，就借了郑沅的名字，想换一条出路。他没想到老妇人。老妇人第一眼就知道他不是她儿子：“我儿子没有这么温柔。”十二年没有人叫过她娘，她认了。他说：“我把屋顶修了三次。她说瓦是他小时候最爱爬的。”

**选。**
- **揭穿。** 核验制度守住，真亲属不会被冒名挤掉名额；石棱回去做债工，老妇人失去“儿子”。伊蕾会难受，但她会做。
- **默认。** 用“例外条款”放行。伊蕾要为此担责；M10 的核验谈判里，矿主会拿这件事攻击整个制度，你的筹码下降。
- **收养。** 石棱以养子登记，郑沅的真名仍留在名册里等人找。条件是老妇人当面叫他“石棱”。她不一定肯，她只会叫郑沅。

**交叉。** 如果你已经做过 RC-05，真正的郑沅就在山上的第三班。他听说母亲有人照顾，一直没下山，因为不知道怎么面对。你可以把两个人带到同一个屋顶下。

**回响。** M15 点名：念到“郑沅”，答的人取决于你；念到“石棱”，老妇人没有答，她的拐杖在地上敲了一下。

## RC-03｜白矶岛的多数

（已写出可朗读的场景稿：[SCENE_SCRIPT_RC03.md](SCENE_SCRIPT_RC03.md)。）

**名册上的一行。** 白矶矿，已核验，二十七人，仍在营区。

**起头。** 鲁斯倒台后，白矶岛由矿工互助会自己管。外人来领人，被当成又一批来抢人手的。岛上有食堂、夜校、病房和轮班表，二十七个晏国人里，二十三个愿意留下。

**查。** 你在岛上住几天，跟轮班、吃食堂、听夜校。罗会长是瑟兰老矿工，真诚，会算账：“走的人带走手艺，留下的人带着窟窿。”年轻的晏国女工蓝箬想走，她父亲在名册里是“下落待查”，她想去找。可每次开口，都被一句“咱们都说好了”拦回去。

**揭。** 没有人强迫她。会章写着：愿走者，须留一年工，并把手艺教给接班人。她是岛上唯一会修二号泵的人，她走，半个岛断水。多数人的善意是真的，岛的脆弱也是真的。她说：“大家说得都对，所以我一句话也说不出口。”

**选。**
- **劝会议改会章。** 要证明岛离了蓝箬也能转。你需要一份修泵的图和愿意学的人；M06 里选过“矿工停机配合”会多一张牌。小七愿意花一周教三个人。
- **帮蓝箬悄悄走。** 潜入与夜航。岛上断水两天，罗会长对你的信任碎了。
- **蓝箬留下一年。** 你帮她寄信、找她父亲，她的承诺由她自己守。她可能恨这个决定，也可能不。

罗会长和蓝箬各自陈述，戏份相当。

**回响。** M15 点名：会改了章，罗会长托人送来一份会章修订本，蓝箬答“在”；悄悄走了，岛上来信一封，信里没有一个字提她；留下了，她会寄来记述一年约定实际进度的回执。**“还有十一个月”是选择后约过一月的早期回信**，若到下一次纪念日已经过了一年，不能把早期剩余期限原样放进 M15 的当下。

## RC-04｜盐雾里的应声

（已写出可朗读的场景稿：[SCENE_SCRIPT_RC04.md](SCENE_SCRIPT_RC04.md)。）

**名册上的一行。** 丁岳，渡引，下落待查。

**起头。** 外港的渔民不肯靠近一片雾，说雾里有人叫名字，应了就回不来（M05 里已经听到过这个传闻）。三个月里三条船撞了礁，两个人没回来。祁雀不肯在那片海过夜。这里的借声兽和钟岭的是同一类东西（见 ST-04），在雾海里的样子。

**查。** 这是第一次需要认真听雾：靠回声的延迟分辨真人和借声兽，真人的应声慢，兽抢答。你在礁区外围试了三次，才分得清。被叫走的人，都是被自己亲人常叫的那种名字叫走的。

**揭。** 礁岛上有一个活人，丁岳，晏国人，十年前被迫给瑟兰商船当渡引，沉船后困在礁上。他每夜对着雾叫旧部的名字，一个一个，怕雾忘了他们。一只借声兽学会了他的声音，开始用它诱船。他不知道，或者知道，不敢承认。他说：“我不是要诱他们。我只是怕雾忘了他们的名字。”

**选。**
- **杀兽。** 阿鸢的歌每遍不一样，兽学不会，他唱起来，兽就会失去目标，这是 M04 的伏笔。丁岳失去他唯一的应答者。
- **引开兽，带丁岳回去。** 渔民遗孀渔婆当面指着他：“我儿子是被叫去的，他听见有人叫他，就答应了。”伊蕾可以调解赔偿，丁岳要上岸做工还债。
- **留兽在礁上，设航标。** 不杀，但每年得有人去守，祁雀的航线要长期绕行，她会算这笔账。

丁岳、渔婆、祁雀各自陈述，戏份相当。

**回响。** 这条案子里学会的听雾，会让 M14 路线 C 的雾中接应更稳。M15 点名：他答“在”，这一次声音没有回声。如果杀了兽，他夜里不再叫名字；渔村为他留了一个位置，或者没有。

## RC-05｜山上的第三班

（已写出可朗读的场景稿：[SCENE_SCRIPT_RC05.md](SCENE_SCRIPT_RC05.md)。）

**名册上的一行。** 第三旅一营三班，班长郝烈等十二人，下落待查。

**起头。** 山路上有伙走私客，专运粮和盐去停战线另一侧的矿营家属。韩峤的巡船和陆钧的招募人都在找他们。传闻说他们过关前先报数，从不丢人。

**查。** 你在山道上跟踪、赶集、辨认暗号。他们每次过关前一个接一个报数，到齐才动。你找到半山的废磨坊，他们先用一桩小交易试你。

**揭。** 他们是八年前集体逃出营区的第三班，一直靠走私把粮送回矿营。你逃走的那个月，是他们的三车盐粮顶着巡逻送进去的，没有这些，死的不止两位老矿工。他们不下山：下山就是逃兵；陆钧会让他们重新入伍，韩峤会把走私当罪。郝烈的名字刻在临潮的石碑上，他母亲每月去擦一次。他在山上，远远看着。十二人里有一位是斥候郑沅，他的母亲在镜湾（见 RC-02）。

**选。**
- **赦免与登记。** 找韩峤谈，换民用身份和走私赦免，条件是停止走私。矿营家属的粮线断了，需要一条新的合法粮路（M10 的供给合同）。
- **引荐陆钧。** 他们入伍，保持班制。陆钧给粮给身份，也把他们编进后来回澜关的部队，他们是否参与强征，取决于你后来的选择。
- **让他们继续走私。** 你替他们遮掩，粮线保住，韩峤的商路和税收受损。

谈崩或误会时有一次山路遭遇，可以避免。郝烈、韩峤的税吏、陆钧的招募人各自陈述，戏份相当。

**回响。** M00 里那位用袖子擦碑的老妇人，就是郝烈的母亲。你让他们下山，M15 点名时十二个人一起答“到齐”；你让他们留山，山里传来一声号子。
