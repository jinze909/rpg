> **读取事实**：`voyage_path`、`pension_path`、`qi_debt_known`、`xiaodou_prompted`。

## 一、船工聚餐与阿鸢的歌

**傍晚。临潮港码头。**
出发前夜，船工们围在栈桥边聚餐。祁雀雇来的舵手**阿鸢**坐在缆桩上，唱起了一首没人知道原词的歌——他连唱了三遍，每一遍的词都不一样。

船工：阿鸢，你刚才第二遍唱的是“白沙埋铁锚”，怎么第三遍又变成“白沙埋旧刀”了？

阿鸢（拨了下弦，笑）：风向都变了，词怎么能死板着不改？

祁雀在旁边端着碗跟着哼，哼错了调也不在意。

---

## 二、小豆的糖人

**小豆**从街口跑来，递给你一个用油纸包着的糖人，说是送给“英雄”的。

小豆：我奶奶让我给你送来。她说坐船的人嘴里苦，吃点甜的。

小豆（仰起脸）：那句“桥在我在”，我今天练了二十遍，再也不会忘词了！

[“其实那天晚上，我喊的是‘谁带了多余的绳子’。”]（`xiaodou_true_line = 已教`）
[“背得好。替我谢谢姜婶，回去早点睡。”]（`xiaodou_true_line = 未教`）

**如果你教她真正的台词：**
- 若 M00 曾帮她提词：小豆（低头看看糖人）：你那天帮我提的那一句，原来是你自己喊的？那听着不像大将军说的话呀。
- 若 M00 没有帮她提词：小豆（愣了一下，低头看看糖人）：……“谁带了多余的绳子”？那听着不像大将军说的话呀。
你：是不像。那天人已经过了桥，缆还绷着。我们得找根绳子，让桥再撑一会儿。
小豆（点点头）：那我记住了。等我长大一点，我就照这句演。

**如果你让她继续信：**
小豆用力点头，祝你一路顺风，蹦蹦跳跳地跑回了西巷。

## 三、甲板上的丑杯子（呼吸场）

**夜里。仍停在临潮的船边。** 这段谈话须祁雀实际在场并愿意送杯，即使她不搭这趟船，也可在拔锚前交给你；若没有见到她或收到杯，后续使用约定的普通信号灯。
海面很静，你和**祁雀**并排坐在靠岸的甲板边。她搬出一只小木箱，里面放着她从各个港口收集来的最难看的杯子。她挑出里头最丑、缺了个口子的黑泥杯，推到你面前。你把杯子装进随船的包里（记录本章“携带杯子”的事实），所以 M14 路线 C 才能用它做识别灯，M16 才能把它带回来；这里不凭空插入一个与后文无关联的拒收结局。

祁雀：**出海带着。丑到你想活着回来换掉它。**

[“这杯子确实丑得让人睡不着。”]
[“等我把沈砾带回来，你得给我换个好看的。”]
[“船贷的事，等这趟回来一起平。”]（若 `qi_debt_known == 是`）

祁雀（晃了晃自己手里的茶杯）：少替我操心。我的商号招牌名字我都想好了，等跑完这一趟，我去刻个印章。你只要别在半道上把命丢了，就算帮我省钱了。

## 四、两份善意

**黎明拔锚前。**
码头一前一后送来两样东西：
1. **韩峤**派随从送来的补给箱上，盖着真实的民用航次印记（即便你未借用官船坞，他仍念及当年白水渡拖他上岸的情分送来这份便利）；
2. **陆钧**的联络人站在岸边，临别提醒了你一句：**“人带回来，总要有归属。”**

启程前确认实际领航船、浅水接驳艇、吃水、舱位与已落实的接应，记入 `landing_capacity`。韩峤船坞提供官船，陆钧护航提供护卫与公开旗号的船，祁雀商路用实际安排的民船；混合航路另记所用底船和随行护卫，不把官船与民船混为一谈。祁雀与阿鸢是否随第一段航程出海，以这里实际谈妥的分工为准；即使选用别人的船，也可以请他们同行。若祁雀不随船，先确认另一位会听雾的领航人。未约到的人留在岸上。

船帆升起，领航船驶入茫茫雾海。
