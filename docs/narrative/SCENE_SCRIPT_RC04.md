# RC-04 · 盐雾里的应声（名册案之四）

> **名册上的一行**：丁岳，渡引，下落待查。
> **开放窗口**：M08 之后开放，至 M10 会盟开幕前。
> **核心升级（三重回声折射声学解谜 + 渔婆亡子阿海凿船真相反转）**：
> 1. **第一层假线索（Red Herring）**：讨命渔婆哭控守礁十年的老渡引丁岳“每晚对着盐雾狂喊死人名字、点歪引航红灯招来借声兽，害死她独子阿海”；
> 2. **误判陷阱**：若不查沉船残骸直接采信渔婆封停引航台，次日夜里三艘归港渔船因无回音测暗沙全部触礁覆没；
> 3. **第二层惊天反转**：通过勘验退潮沉船龙骨与阿鸢的高阶听雾辨音，发现死礁地底有每三天一变的活沙暗流，丁岳十年如一日每晚对雾喊十一个亡友名字，是在用**礁石缝隙反射人声的回音延迟（人肉声呐）**测算安全水道！而借声兽之所以只模仿“别砍我腕子”的哭喊，是因为**十年前和上个月，正是渔婆的儿子阿海为了独吞走私沉银，在雾里挥刀砍断了同伴的救生绳**，借声兽吞食了被害者的临死怨音！丁岳认下“灯提歪了”的渎职罪，是为了给绝户的渔婆留最后一点念想。
> **出场人物**：你、祁雀、舵手阿鸢、丁岳（困礁老渡引）、讨命渔婆。
> **写入事实**：`rc04_resolution`（`1`=杀兽并揭穿阿海罪行, `2`=杀兽/引兽但瞒下阿海罪行让渔婆添油赎罪, `3`=封停引航台）、`skill_fog_mastery = true`（解锁阿鸢生还汇聚锁 Key 1）。

## 第一场：讨命的鱼叉与三重回声折射（4E 声学侦测）

**【画面与第一层假线索（Red Herring）】**
傍晚。赤盐外港东南三十里的外海死礁区。墨黑的海水里戳出无数犬牙交错的暗礁。
随船跟来指认水路的**渔婆**捧着独子阿海的空灵牌站在船头，手握一把磨得雪亮的铁鱼叉，指着浓雾中心那座闪烁着微弱红灯的孤礁哭骂：
“就是丁岳那个老狗！十年前他自己领沉了十一船弟兄不够，这十年每天半夜对着盐雾鬼叫死人名字，把吃人的借声兽招来安了窝！上个月我儿阿海出海打鱼，听见雾里有人叫他名字，心善答应了一声，连人带船撞碎在死礁上！官爷，今天必须砸了他的引航灯，砍他的手祭海！”

**祁雀**握紧舵轮：“前面三重暗礁都在反射回声，别听风就是雨，先把声呐罗盘打开！”

**【玩家操作：高阶“三重回声折射”辨音面板（写入 `skill_fog_mastery = true`）】**
死礁周围存在主礁（延迟 1.5 秒）与副礁（二次反射延迟 3 秒）的声学迷宫，借声兽就躲在副礁后模仿二次回声：
1. **探针发射**：玩家让**阿鸢**唱出半句无词哼鸣作为基准声波探针；
2. **波形比对**：在返回的三道回声中，找出混在 3 秒副礁反射波里那道**“抢拍 0.2 秒且带着哭腔求饶的假尾音”**；
3. **听清假尾音的真实内容**：**阿鸢**突然睁大眼睛，脸色煞白地拉住你的衣袖（`Portrait: 阿鸢_Shocked`）：
   阿鸢：“船长，不对！你仔细听那头借声兽模仿的尾音——它喊的根本不是阿海落水求救的声音！它最后那句‘别砍我腕子’，喊的是**‘阿海哥饶命’**！是阿海死前，有人在水里求阿海！”

## 第二场：退潮龙骨上的凿孔与孤礁老渡引（第二层反转）

**【玩家操作：勘验死礁退潮沉船与守礁日志】**
趁着傍晚退潮，你和祁雀、阿鸢登上中心孤礁，在丁岳的石洞外勘验两处铁证：
1. **`[调查：浅滩露出的阿海渔船残骸龙骨与断指浮木]`**
   祁雀摸过船底龙骨，眼神一冷：“这船根本不是撞礁沉的。底舱龙骨被人从里面用凿子蓄意凿穿了三个漏水孔——这是黑船伪造海难私吞走私银的惯用伎俩！而且这块救生浮木边缘，留着被柴刀剁断的同伴手指印！”
2. **`[调查：石洞里丁岳用鱼骨刻的十年守礁水文图]`**
   洞里蜷缩着瘦骨嶙峋、嗓子已经咳出血丝的老渡引**丁岳**。石壁上刻满了密密麻麻的回音秒差——原来死礁地底有活沙暗流，水道每三天一变；丁岳十年不肯离礁，每晚对着浓雾挨个呼喊十一个亡友的名字，一方面是**“怕我不叫了，这片雾就把他们的名字彻底忘光了”**，另一方面正是靠**十一个名字在不同礁缝间的回声延迟，每晚为过往渔船测算活沙暗流的最新安全航道**！

## 第三场：断崖引航台的三方对质

**【画面与 2D 演出】**
夜幕降临，浓雾翻涌。雾中借声兽再次发出重叠的拟声哭喊：*“娘……好冷啊……丁叔把灯提歪了……拉我一把……”*
**渔婆**听见这声音，浑身筛糠般颤抖，猛地挺起铁鱼叉刺向丁岳胸口（`Anim: Fishwife_Thrust_Spear`）！

渔婆：你听！我儿阿海在雾里喊冤呢！丁岳，你每晚鬼叫招来脏东西，害死我唯一的独苗，我今天跟你拼了！

**丁岳**不躲不闪，任由鱼叉尖刺破破棉袄渗出血珠（`SFX: Cloth_Pierce`），哑着嗓子咽下一口血沫：

丁岳：……是我那天夜里灯提歪了。官爷，名册上记我渎职吧。只要等今晚子时我把最后一遍礁位喊完，把这十年的《死礁声呐水文图》交给你们，我这条命赔给阿海娘。

阿鸢在旁急得直跺脚：“丁大爷！她儿子阿海明明是在雾里砍断了同伴的手腕抢走私银，才被借声兽盯上拖进水里的！你干嘛替那个畜生背黑锅？！”

丁岳（死死按住阿鸢的手，浑浊的眼睛看着满头白发的渔婆，声音沙哑如破风箱）：阿海十年前跟船的时候，也往那个水坑里推过人……可他已经喂了鱼了。这老婆子就剩这一口气活着，你告诉她她养了个杀同伴的畜生，她今晚就得跳下这断崖。……让她恨我吧。恨一个活人，比恨一个死人好受。

与此同时，海面剧烈翻涌，成年借声兽顺着争吵声爬上孤礁外围！**阿鸢**拍了拍琴箱站上礁石高处：“它学得像，是因为丁大爷十年念的名字都是固定的。**可我的歌，每一遍词都不一样，它怎么学？**”

> **【角色路标（Signposting）】**
> 祁雀拔出短铳指向雾中巨兽，转头冲你喊：“阿鸢唱歌破它的声囊！但脚下那块带刀痕的断指浮木——你是要现在甩在渔婆脸上还丁老头清白，还是扔进海里替死人瞒到底？！”

> **【玩家抉择：`[决定]` 破局与真相处置（写入 `rc04_resolution`）】**
>
> * `[决定 A · 阿鸢变调歌杀兽 + 当场甩出断指浮木揭穿阿海罪行（rc04_resolution = 1）]`
>   阿鸢放声高歌，现编词句每拍一换，借声兽声囊卡壳狂乱，你带队突入将其斩杀！随后你把那块带刀痕的浮木拍在渔婆面前：“睁眼看看！丁岳十年喊礁救了上百条船，是你儿子阿海自己凿船砍断同伴手指才喂了鱼！”
>   - **代价与后果**：丁岳十年冤屈彻底洗清，交出《死礁十年声呐水文图》（**M10 绝杀陆钧强渡谎言的铁证，M14 路线 C 获得丁岳崖顶声呐领航**）；但渔婆看着浮木上的刀痕，精神彻底崩溃，抱着空灵牌疯疯癫癫走入夜雾。
>
> * `[决定 B · 阿鸢变调歌杀兽/引兽 + 将断指浮木踢入海中，让渔婆每日上礁添油赎罪（rc04_resolution = 2）]`
>   你一脚将断指浮木踢下深海，对渔婆冷声道：“阿海是为了帮丁岳测暗流死在礁上的。从明天起，丁岳上岸养嗓子，这死礁上的引航灯，由你每天挑灯油上来替你儿子点亮！”
>   - **代价与后果**：同样获得《声呐水文图》与 M14 领航加成；渔婆哭倒在地，余生守着引航灯替儿子赎那桩她永远不知道的罪；丁岳随船上岸，但阿鸢事后心有余悸地对祁雀说：“我以后再也不敢在雾里唱歌了。”
>
> * `[决定 C · 采信渔婆或留兽封海：封停死礁引航台，商船永久绕行（rc04_resolution = 3）]`
>   - **代价与后果**：死者的回声留在雾里，但祁雀的商船航线必须永久绕远路，且 M14 失去死礁水道支援。

**【M15 终局点名回响】**
当念到“丁岳”时，嗓音沙哑的老渡引在台下答了一声**“在”**——这一次，晴朗的广场上干干净净，没有任何雾里的回声。当继续点到死礁那十一名亡友的名字时，阿鸢（或船工）唱出十一段不同旋律的应答曲，丁岳在每一声尾音落下时重重敲响一次引航铜钟。
