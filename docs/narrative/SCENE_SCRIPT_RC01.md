但当你向渡口巡街的**稽查吏**打听“陈砚”与前妻**林素**（现改嫁镇上**方木匠**）时，稽查吏却神神秘秘地把你拉到巷口：

## 第三场：后巷细雨里的三方对质

**【画面与 2D 走位演出】**

林素（指尖掐进门框，声音发颤却没看陈砚）：当家的，别说了……把门关上。孩子受不得风。

你（亮出柴房铁勺与灶台《领粮实录》）：不认识？那你床底暗箱里那把刻着“三班陈”字的铁勺，是怎么来的？

**陈砚**猛地抬头（`Emote: !`），第一次发出沙哑如砂纸摩擦的声音，急促摆手：
“别问了！客人，饼钱我不收你的，那铁勺是我当年逃回城门口，见林素抱着高烧吐血的孩子没钱抓药，我自己连着阵亡铭牌从门缝塞进去让他们去换抚恤银的！
我是抗命逃兵，跟他们两口子没半点关系！”

此时，门内的**林素**突然开口，眼圈通红却字字清晰：

【林素 · 改嫁缝衣妇】：**“那天在城门口，我认出他了。”**

林素：夫妻十年，他化成灰站在人群里我也认得他的肩膀。可我怀里的孩子烧得直抽搐，方大哥为了给我们母女借药钱差点把铺子卖了……我当时看着他把铁勺塞进门缝，转过身一步一步走得很稳。我要是一嗓子喊住他，三十两抚恤银就成了“逃兵家属骗饷”，方大哥得进大牢，孩子当晚就得断气，陈砚也得被砍头！所以我把嘴唇咬出血，硬是没喊！

**秋娘**此时也牵着七岁的阿河从渡口跑来，跪在雨地里拉住陈砚的衣角：“官爷，如果您非要把他变回那个‘陈砚’，按律前婚恢复，我和他这八年就算无媒苟合，阿河一辈子都是没户籍的私生子，方木匠一家也得退赔双倍抚恤银去坐牢啊！
