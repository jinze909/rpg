# M07 · 把还活着的人带出来（可朗读场景稿）

“归来”为工作标题。本稿为第二幕高潮，承接 [STORY_OUTLINE.md](STORY_OUTLINE.md)、[CHARACTERS.md](CHARACTERS.md) 与 [BANTER_LINES.md](BANTER_LINES.md)。方括号是玩家选项或操作。

> **出场人物**：你、沈砾、欧林、鲁斯、梁伯、小七、易达、陶霁、祁雀、阿鸢。
> **读取事实**：`rescue_plan`、`voyage_path`、`landing_capacity`（先遣船、浅艇和外港实到接应）、`letters`。
> **写入事实**：`rescue_route_cost`（按 M06 方案记录实际代价）、`rescue_priority`（对鲁斯、证据、额外矿工或船只的优先级）、`rus_fate`、`survivor_liang`、`survivor_xiaoqi`、`survivor_yida`、`survivor_taoji`、`letters`、`shen_relation`（若强带梁伯）、`rescue_manifest`（赤盐转运去向）、`landing_capacity`（本航次已用运力）。
> **章末留给玩家的问题**：“明年谁给剩下的人付粮”，谁来答？

## 一、营救之夜：四条路，同一个不能淹人的底线

**夜。赤盐地下泵房与通向码头的通道。**

**四种 M06 方案互斥演出，写入 `rescue_route_cost`；只有真正选择且执行了停机配合，才使用“三小时停泵”版本：**

- **`[rescue_plan == 矿工停机配合]`** 修理班以大修名义引导**下层五百人先撤到不会进水的上层集结区**，训练接手人、接通备用手摇泵后，主泵才安全停三个小时。接班人收好修泵图；你可以抄一份带走。沈砾拍了拍机壳：“**对不住了，老张。**”（老张既是她给泵起的名字，也是那个没熬过断粮月的老矿工。）她拉下总闸，亲自确认备用排水运转；你要为留守者承担后续泵机检修与轮班费用。**五百人撤出下层，不等于五百人已离岛。**
- **`[rescue_plan == 监察移交]`** 伊蕾凭核验副本争取合法的**分批放行窗口**，你逐一核对人名与通行名单、护送他们通过检查；主泵维持运行，沈砾交代接班人而**不拉下总闸**。监查手续慢，船只停港和补给债增加；若押运者拒绝放人，先补证据或延后下批，不把未登船者写成获救。
- **`[rescue_plan == 货运掩护]`** M06 实际谈妥的承运人用盐箱、夜间货单和分批倒运的浅艇掩护愿离岛者，你亲自核对舱容和藏身位置，欧林清掉货道锁具；主泵不停。货物让位给人，丢失一笔运费并牺牲本次载货量；不能凭空把小商船写成能一船载三百人。
- **`[rescue_plan == 强行突围]`** 你先确认撤离通道已打开、非战斗矿工在掩体后，再带自愿的护卫夺取栈桥与巡逻艇的控制权；主泵仍由留守工匠安全维持运转。正面冲突造成码头损毁和救治、修复债，不自动把整座矿岛夷为平地或当作无伤成功。

若所选方案在现场受阻，**先结算已发生的损耗，再经伊蕾重新核验转为分批监察移交**；基本营救可延后继续，但不播放失败方案的成功动作，也不把下层五百人算作一船获救。

**【欧林开锁】**
**欧林**带人一路开锁。轮到最外层那把当年他被拿家人要挟着修过的暗锁，他没说话，用的是反着的手法。
锁开之后，他在通道边的水桶里把手洗了很久。

通道尽头，一道本该上锁的闸被人从里面拨开——是管事**易达**，他站在暗处，没有看你。
外港海面上，巡逻艇每隔二十分钟扫过一次码头。你按所选 `rescue_plan` 的**实际时间窗口**、来时的 `voyage_path`、浅艇和外港接应大船运力，决定哪条小艇什么时候靠岸。**仅矿工停机方案有三小时的停泵期限**；其他路线以核验、货船或夺港后实际取得的窗口为准。按约三百人筹划首批运力，分批送上外海接应船队。到跳板前才按本人意愿、实际就位的船与空舱逐人勾记。等下一班、留居和撤到安全层各自有去向，只有实际离岛的人算入本批；上层撤险仅停机线另记。

## 二、鲁斯的茶与问题

**夜。矿务账房。**
你把**鲁斯**逼到账房。他没有拔武器，先给你倒了一杯热茶，温和地问你路上晕不晕船。
然后，他翻开桌上的账本给你看：每个人的口粮单价、每个死去矿工的“损耗”栏。他没有为自己辩解，只是抬头问你：

鲁斯：**你们要把人带走，明年谁给留下的人付粮？**

（这个问题留给你，答案在 M10 的供给合同里。）
话音落下，鲁斯点火烧账——但证据已经分散在矿工的记账、船单和监察副本里，烧掉一本账册并不会让追责失效。

> **【玩家抉择：撤离窗口的优先行动（写入 `rescue_priority` 与 `rus_fate`；不因没选某项取消已完成的基础营救）】**
> - `[优先抓捕鲁斯：当场控制他并交监察看管，侧道物资与部分原始账页来不及取（rescue_priority = 抓捕；rus_fate = 被捕，账册部分烧毁）]`
> - `[优先保住账册原件：扑灭炭火抢出核心账页，鲁斯趁夜色退走（rescue_priority = 保账；rus_fate = 逃亡，账册保存）]`
> - `[优先去支道接出额外一组受困矿工：先问其意愿、打通小艇和安置，人数以实际核对为准，需另占运力与供给，鲁斯退走（rescue_priority = 额外救援；rus_fate = 逃亡，账册部分烧毁）]`
> - `[优先保障本航次船只安全与处理确实收到的回信：不再冒险追鲁斯或抢原本，先让已经登船的人稳妥离港（rescue_priority = 安全撤离；rus_fate = 逃亡，账册部分烧毁）]`

（**额外救援只在实际找到了自愿离开的矿工、落实舱位和接纳地时**才增加已救人数及 `landing_capacity` 的消耗；不凭“额外一组”四字虚构人数。`rescue_priority = 安全撤离` 也不自动生成信件：只有 M05 确实接信、M06 确实送到对应收件人且收到了回信，才带回确实收到的那部分；在世者可以不回，也可能写满一整页。收信人已故且死讯核实的，原信单独标为退件，带回交还寄信人；去向未明的信仍待投递。）

## 三、码头点名

**黎明前。赤盐码头。**
**沈砾**拿着实际取得的记录站在船跳板前，一个一个念名字。原件不在时，用实际取得的监察副本、抄录名单或现场见证补核；尚未落实的名字留在待接名单。只有实际到达跳板、愿意且有舱位的人应声并登船。

沈砾：梁伯。

**梁伯**：在。——我不走。我在营里娶了瑟兰寡妇，有两个混血的孙辈，这儿有人给我留饭。

> **【玩家抉择：梁伯的去留（写入 `survivor_liang`）】**
> - `[尊重梁伯的意愿，让他留在岛上（survivor_liang = 留下）]`
>   你：好，留在岛上保重，回头托商船给我们寄盐煎鱼。
> - `[劝梁伯先随船避一避：只有他本人明确同意，才记 survivor_liang = 被劝走；若最终拒绝则尊重并记留下]`
> - `[违背梁伯意愿坚持强带：沈砾当面阻拦后仍调船工强行带走（survivor_liang = 被强带，shen_relation 记严重伤害）]`
>   你刚让人去拉他，沈砾一步跨过来站到梁伯那边拦住你：“他答了‘在’，走不走由他自己定。”若你收手，梁伯留下，记为 `survivor_liang = 留下`；**只有玩家明确再次坚持**，才会绕过她的阻拦将梁伯真的带上船。沈砾不会原谅这一次，梁伯上船后也不再同你说话；M15/M16 仍记得这笔损害。

（路过外港盐滩时｜沈砾：“这里的盐比临潮的苦。”）

沈砾继续往下念：

沈砾：欧林。

**欧林**（把开锁包往肩上一搭）：**在。别搜身。**

**仅陶霁到达跳板且愿意登船时**：

沈砾：陶霁。

**陶霁**（背着木工包，停下脚步）：**在。**
（她实际安全离岛后才写 `survivor_taoji = 已接出`，并保留这是她第一次答“在”的事实。若未接出，就留在待接名单，本段及回航专属对白跳过。）

沈砾往下念。小七没有名字，她念的是他的编号：

沈砾：七十二。

**小七**（愣了一下，挺直身子大声答）：**在！**

点名快结束时，管事**易达**站在码头边缘，没有人念他的名字。他自己走过来：

易达：**我也在名册里。** 刚才那道闸是我开的。

> **【玩家抉择：易达的去留（写入 `survivor_yida`）】**
> - `[带走易达上船：他是对付鲁斯最硬的证人，但矿工们对他扣过口粮耿耿于怀（survivor_yida = 带走）]`
> - `[把易达交给已接应的镜湾监察方看管作证：只有实际交接才写 survivor_yida = 交给监察；未能交接时仍须决定带走或留下]`
> - `[不带易达走：一码归一码，开闸之情抵不掉扣粮旧怨（survivor_yida = 不带）]`

**【幕末】**
沈砾最后一个踏上船板。她站在船舷边，对着岸上还想走、正在等下一班的人大喊：

沈砾：**下一班我来接。**

（这是她的承诺，也是 M09 的起点。）

## 四、回航：船舵榫与三类名册

**海上。回航。**
仅陶霁确已接出并在玩家这条船上时，三十出头的女木匠**陶霁**才第一个发现船舵榫松了，当场一声不吭地修好，然后小声对自己说了一句：

陶霁：**家里缺个会修东西的人。**

（她一连说了三遍，记录玩家确实同船听到这一幕。陶霁未在这条船上时，由实际在船的船工处理舵榫。）

**与沈砾（回航之后）｜闲聊（两人都实际在场）：**
陶霁：这舵榫我又紧了一遍。
沈砾：我没看。
陶霁：你看了。
沈砾：……手艺行。

**雾里｜沈砾与欧林：**
沈砾：雾真大。
欧林：别叫我的名字。
沈砾：我叫的是“老欧”。
欧林：那也是名字。

**第一次出海｜小七：**
小七：海没有边，天也没有边，那它们是怎么分开的？

阿鸢若确在本班回航船上，在船尾唱起那首歌的又一个新版本。
你翻开营救取得的记录：**已离岛**的人注明航次和实到地点（海上仍记在途）；**仍在岛上**的人分记本人愿留、愿走待接或身在其他营区；待查者保留最后核实的线索。到接纳点再补记上岸地点，由这份逐人记录交给 M09 排后续舱位。
