# M07 · 把还活着的人带出来

> **章节定位**：第二幕高潮，赤盐大营救（全剧核心转折点）。
> **核心目的**：植入**鲁斯“记管事五十八岁整寿送护膝、笑着把真账丢进银丝炭盆”**的镜子大师级反派压迫感；打破“数到三”的刻板套路；通过**账房限时 4 选 2 行动点**、**码头三联名册分类锁定**以及**梁伯/小七/易达的激烈登船冲突**，把营救推向最高潮。
> **出场人物**：你、沈砾、欧林、小七、梁伯、易达、鲁斯、老周管事、矿工阿石、陶霁、祁雀、阿鸢。
> **读取事实**：`rescue_plan`、`letters_delivered`。
> **写入事实**：`rus_status`、`rus_ledger_saved`、`m07_extra_miners`、`survivor_liang`、`survivor_xiaoqi`、`survivor_yida`、`letters_delivered = 2`。
> **章末留下的问题**：鲁斯问的“明年谁给剩下的人付粮”，谁来答？

## 第一场：停机之夜、反套路拉闸与欧林的暗锁

**【画面与 2D 演出】**
深夜，暴雨将至。三百名矿工与旧兵借着夜色往旧码头集结。
沈砾站在那台最大的排水泵前，最后检查了一遍手摇备用阀，抬手轻轻拍了拍铸铁机壳。

**沈砾**（轻声）：对不住了，**老张**。

她手握总闸拉杆，看向你：“准备好了？我数到三就拉闸——**一！**”
话音未落，根本没数“二”和“三”，沈砾猛地一把将总闸拉到底（`Anim: Pull_Lever_Fast` + `SFX: Heavy_Switch_Clunk`）！

你（一愣）：怎么不数完三？

沈砾（抓起扳手就往外跑）：数什么三！等数到三鲁斯的狗腿子都把门焊死了！快走！

**【欧林的“三分锁”与冷水洗手（潜台词高光）】**
矿道出口处，**欧林**蹲在最外层那把结构精密的双簧暗扣铜锁前，用两根探针探进锁孔听了一声“咔”。

欧林：三分。连三分半都勉强。

沈砾：你管这叫三分？我拿“税务官”别了半天都没撬开半条缝！

欧林（声音冷得像冰）：铁料给足了五分，簧片也是瑟兰内城的规制。但留气孔被故意封死了，倒钩往里偏了半毫——造这把锁的人，从画图那天起就没打算让人从里头活着推开。手艺越精，心肠越烂，扣两分。

（欧林手腕反拧，`Anim: 欧林_ReverseGrip_Unlock` + `SFX: Double_Spring_Click`，暗锁弹开。众人冲出门后，欧林没有看门后的路，径直走到角落水桶边，舀起一瓢刺骨的舱底冷水，一声不吭地反复搓洗右手食指与拇指指腹，`Anim: Wash_Hands_Loop`。）

你：欧林？里头的暗钩是你当年被威胁着……

欧林（盯着水面上浮着的一层铜绿油星，把水瓢重重按进桶底）：水脏。去前舱拿块干布来，别拿这桶水擦刀。

通道尽头本该锁死的最后一道铁闸，被人从里面拨开了一条缝。**易达**提着熄灭的马灯站在阴影里，没有看你一眼，侧身让出了路。

## 第二场：鲁斯的生日护膝、熟普茶与“4 选 2”限时决断

**【画面与反派压迫感演出】**
你带人踹开码头侧后方的矿务账房花厅（`SFX: Door_Kick_Open`）。
花厅里炭盆烧得极旺。**鲁斯**没有逃，也没有拔枪，他正站在门口，亲自替浑身发抖的**老周管事**紧了紧领口的羊皮袄。

鲁斯（温和得像在拉家常）：老周，今儿是你五十八岁整寿吧？去岁你害寒腿，我让人从南边捎的艾绒护膝，搁在偏厅匣子里了，下值记得拿回去，别让你家那刚满周岁的孙子等急了。

老周管事（嘴唇哆嗦，跪了一半被鲁斯温和地托住肘子）：东家……我……

鲁斯拍了拍老管事的手背示意他退下，随后转头看向你，拎起紫砂壶替你斟了七分满的熟普（`Anim: Pour_Tea_Calm`）。

鲁斯：雨天路滑，几位鞋底都带了矿泥。趁热喝口茶暖暖胃——这茶不贵，但火候足，不伤脾。

你：鲁斯，三号坑道克扣口粮和转卖债工的真账，就在你手边那个红木匣里。交出来。

鲁斯（微笑着点点头，顺从地打开红木匣，取出那本厚厚的蓝皮真账，双手捧到通红的银丝炭盆上方）：你要公道，这册子就是公道。我一个生意人，哪敢跟几位好汉拧着干？

**【高潮演出】**
在你伸手去夺的前一秒，鲁斯手腕轻轻一松，蓝皮账册不偏不倚落进通红的炭火里，火苗“轰”地舔上油纸（`VFX: Fire_Blaze` + `SFX: Fire_Ignite_Whoosh`）！鲁斯拿起茶盖，慢条斯理地撇去自己杯里的浮沫，抬头温和地看着你。

鲁斯：只是几位把鲁某送进大牢之后，还请顺手替我算一算——**白矶和赤盐底下那三百二十户还没停火的灶台，开春头一船过冬的糙米，是港务司的韩大人掏腰包，还是几位英雄拿命去抵？**……茶要凉了，请。

> **【角色路标（Signposting）】**
> 欧林冲进门半格（`Emote: !`）：“巡逻艇探照灯转回来了！最多还有十息，鲁斯往后窗快艇退了，火盆在烧账，后山滑道还有二十个矿工被困，船底水密门也得封——**咱们只有两个人手，最多只能顾两头！**”

> **【玩家操作：账房危机“4 选 2”限时行动槽（写入原子化变量）】**
> 玩家从以下 4 项中选择 **2 项** 执行，未选的 2 项当场在镜头内承受真实损失：
> 1. `[行动 A · 翻窗追击生擒鲁斯]` → 写入 `rus_status = 1`（若不选，鲁斯乘快艇逃往回澜关 `rus_status = 0`，M09 哨卡盘查难度提升一级，M10 由其代理人出面竞价）。
> 2. `[行动 B · 扑火抢救半册核心总账]` → 写入 `rus_ledger_saved = true`（若不选，总账烧成灰 `rus_ledger_saved = false`，M10 需靠矿工私记与船单拼凑证据链）。
> 3. `[行动 C · 分兵接应后山滑道被困的二十名矿工]` → 写入 `m07_extra_miners = true`（若不选，M08 分粮时矿工代表会摔碗质问，失去 M11 矿工爆破组加成）。
> 4. `[行动 D · 封死货船底舱水密隔舱并收齐八封回信]` → 写入 `letters_delivered = 2` 且保障船体完好（若不选，底舱进水导致回航船速降低，陶霁被迫昼夜修船）。

## 第三场：码头点名分类与跳板上的拔刀对峙

**【画面与机制合流：点名 + 三联名册快速核验】**
天边泛白，浓雾聚拢。三百名获救者挤在栈桥上，既混乱又急促。
没有人像早操一样整齐划一地深情喊“在”——有人喊“上了！”，有人喊“别挤！”，只有当**沈砾**拿着转运名册点到关键名字时，才触发特写与核验：

1. **梁伯的去留**：
   沈砾：梁伯！
   **梁伯**举着那口煎鱼铁锅（`Anim: Raise_Iron_Pan`）：“在！——老子不走！这儿有寡妇给我留饭，有俩混血孙子，你们回去替我给老家坟头烧柱香就行！”
   - `[决定 1 · 尊重梁伯（survivor_liang = 1）]`：“好！保重，有空托船捎咸鱼！”
   - `[决定 2 · 强行架他上船（survivor_liang = 3）]`：你刚迈出 1 格，沈砾横向一步死死挡在你面前（`Portrait: 沈砾_Angry_Block`）：“谁走谁留，让人自己定！”（梁伯留岛，但 `shen_relation -= 1`）。

2. **小七（七十二号）的第一次应名**：
   沈砾低头看下一行，停顿一秒，念出一个编号：**“七十二号！”**
   蹲在缆桩旁的**小七**弹起 `Emote: !`，猛地蹦起来站得笔直（`Anim: Jump_Stand_Straight`），用尽全身力气喊出一声：**“在！”**

3. **易达登船争议（矿工堵跳板）**：
   点名将尽，管事**易达**半截裤腿泡在泥水里，抓着缆桩走到跳板前，声音极小：“……我也在名册里。刚才最后那道铁闸是我开的。”
   年轻矿工**阿石**猛地横举铁钎挡在跳板前，眼睛通红：
   阿石：“前月三号坑断粮，老张和哑巴死的时候，他的粮仓锁得比铁桶还紧！今天他敢上船，我们就跳海！”
   易达（死死抓着跳板）：我不按规矩锁粮，鲁斯第二天就会灌水封井！而且我有鲁斯和镜湾三位税官分赃的暗账，上了船我给你们当狗都行！
   沈砾（按住管钳看向你，**路标台词**）：“潮水漫过第三级石阶了，跳板只能再留十息。带他走，舱里这群弟兄路上早晚闹事；撇下他，到了镜湾和回澜关就少个人证。你发话！”

> **【玩家抉择：`[决定]` 易达处置（写入 `survivor_yida`）】**
> - `[决定 A · 准易达登船，卸下铁钎将他关入底舱看押（survivor_yida = 1）]`
>   你：“上来！阿石，把钎子放下——他的嘴留着到镜湾咬鲁斯，路上吃死囚口粮，到了岸再跟你们一笔笔算总账！”（**中程连锁**：M09 夜航船舱将触发矿工围堵易达事件，需排床隔离）。
> - `[决定 B · 留易达在栈桥等待镜湾监察船接管作证（survivor_yida = 2）]`
>   你：“你留在栈桥，天亮伊蕾的监察船靠岸，你拿暗账换活命。”
> - `[决定 C · 一脚踢开跳板，将易达撇在码头（survivor_yida = 3）]`
>   你：“赤盐的账就在赤盐结。闸的事两清了，自己活命去吧——拔锚！”（矿工士气大振，但 M10 少一名现场污点证人）。

**【幕末定格】**
沈砾最后一个踏上跳板，双手扶在船舷木栏上，迎着海风对岸上留下的人大喊：
**沈砾：下一班我来接！**
