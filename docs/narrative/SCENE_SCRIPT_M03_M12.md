# M03 与 M12 场景稿：陆钧 v0.1（可朗读版）

“归来”为工作标题。本稿是可改的写作基线，用来验证全剧最重的两场戏：M03 陆钧自承，M12 钟楼下对质。对白不是最终文本。方括号是玩家选项。

---

## M03 · 海边的旧军旗

**傍晚。海边。** 一片收了网的滩涂上，陆钧的旧部在列队，不到两百人，穿的不是军服，是各种颜色的旧衣，只有袖口缝着同一条蓝布。

陆钧站在队前，手里一本很旧的册子，翻开着。他没有低头看，他记得。

陆钧：第三旅，一营。赵得福。

队里有人：在。

陆钧：钱满仓。

（没有人答。他停了一拍。）

陆钧：钱满仓。

（还是没有人答。）

陆钧：钱满仓。

（三遍。没有人答。他在册子上轻轻点了一下，没有划，接着念。）

一个老兵站在你旁边，压低了声音。

老兵：每晚三十个，不论生死。念完一整本要三十七个晚上。他念了好几遍了。

**点名结束，队散了。** 陆钧把册子合上，朝你走来。

陆钧：你来得比我预想的早。

[“我来问桥。”]
[“你念的那些名字，有我的。”]
[“我需要一条船。”]

（选哪个都会走到下面。）

陆钧：你问。

你：桥是谁断的？

陆钧：总帅令。三更。工兵队。

你：你知道。

陆钧：我知道。

（他没有躲开你的眼睛。）

陆钧：你想知道我为什么没说。

你：我想知道。

陆钧：那天晚上我接到命令，第三旅不撤。三更断桥，不能告诉任何人。我是旅正，我接了。

陆钧：我数过。桥这头一万四千，桥那头一千一百。我没说，是因为我说了，防线天亮前就会散在黑里，一千一百人死在黑里。我没说，天亮以后，还有人排队投降。

陆钧：我用他们的不知道，换了他们的命。

（海风把他袖口的蓝布吹了起来。）

陆钧：这个选择，我十二年没睡好。

[“你该说的。”]
[“你替他们决定了。”]
[（沉默）]

**如果你说“你该说的”：** 陆钧：对。我每晚都在想这句话。你让我现在去说，他们会问我，为什么现在才说，我答不上来。

**如果你说“你替他们决定了”：** 陆钧：是。（停）我到现在还在替他们决定，你看出来了。

**如果你沉默：** 他等了很久，没有开口，也没有催你。

陆钧：有件事，我想请你。

陆钧：他们的家人，以为自己的儿子是死守桥头的英雄。你拿走这个，他们什么都不剩。

陆钧：别告诉他们。

[“我不会告诉他们。”]
[“我还没决定。”]
[“我不能答应你。”]

**如果你说“不会”：** 陆钧：谢谢。（停）不用谢我。你什么也不欠我。

**如果你说“还没决定”：** 陆钧：好。决定了，告诉我一声。我不拦你。

**如果你说“不能答应”：** 陆钧：那我也不拦你。（他把册子递给你看一眼）只是你去说的时候，先想想，每一个名字后面站着几个人。

## M12 · 一面旗帜不等于每个人

**回澜关。钟楼下。** 钟楼的门开着，风从里面出来。陆钧一个人站在台阶上，没有带副手。

陆钧：你一个人来的。

你：沈砾在外面。

陆钧：我知道。我让她进来了。

（他看了一眼钟。）

陆钧：这钟，三下。你听见的时候，是不是也会数？

[“会。”]
[“你怎么知道？”]
[（沉默）]

陆钧：我也会。十二年，我每次听见钟声都数。

**他从怀里取出一册名单，一叠船票，一张借据。**

陆钧：这是我救回来的四百一十二个人。这是我借的船，每一条。这是还欠着的钱。

陆钧：你想要的归途，我给了。

你把另一页放到他面前。上面是被他的副手收走船票的人的名字，还有被征用的几条私人渔船。

陆钧：那是我下的命令。不是副手失控，是我的命令。

（他没有看你放下的那页。）

陆钧：停战八年，赤盐还有人，白矶还有人。我没有一条船是干净的，没有一条路是干净的。我选了最快的那一条。

[“有人不想再打。”]
[“你把别人的路收走了。”]
[“你上次也是这么说的。”]

**如果你选第三个：** 陆钧沉默了一会儿。

陆钧：……是。上次也是这么说的。

陆钧：桥这头一万四千，桥那头一千一百。我现在睡不着，还是会再数一遍。得数还是对的。

（他抬头看钟楼。钟声响起时，他的嘴唇也在动。）

## 三个人各自来找你（M12 之前，顺序随你）

**沈砾（主张公开）**
沈砾：我看过缆口。我不想让一千一百个人替一个谎言站岗。但你公开，姜婶会第一个断了钱，我也知道。我只是想你选的时候，什么都知道。

**姜婶（主张不公开）**
姜婶：我不是怕钱。我是怕小豆长大了问我，他的英雄是谁。我得有一句话能答。

**韩峤（主张设“愿知者名册”）**
韩峤：我可以设一个地方。愿意知道的人来问，我把底稿给他们看。不愿意的，不用知道。我签过一次字，我可以再签一次。

伊蕾（站在旁边）：名册要有副本，要有可抽查的人。我可以做。

## 写作笔记

- 陆钧的话全是数字和事实，从不用形容词。他的难受只出现在停顿和袖口的蓝布上。
- M03 里不要让玩家被他说服，也不要让玩家被他吓到。他只是一直在等你问。
- M12 里陆钧不辩解、不求原谅，这是他最危险的地方：你找不到可以反驳的缝。
- “数到三”在 P0、M11、M12 各出现一次，M12 是最后一次，也是他第一次和你一起数。
