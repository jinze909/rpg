# 《归来》叙事事实登记表 v0.3（原子化强类型·多智能体辩论修订版）

“归来”为工作标题。本表基于 8 位叙事与工程专家子智能体的辩论审计结论重写，将原有的复合字符串状态拆解为 **供未来 ORK 3 / Makinom 2 任务分解参考的原子化强类型变量建议（`int` / `bool`）与物品检查建议（`Inventory`）**，意在减少跨章覆写与分支软锁；**这些变量名尚不是仓库中已实现或已验收的 API**。

职责沿用项目基线：ORK 管任务、物品与存档，Makinom 管交互 Schematic 与剧情分支，Unity 管 2D 表现。
