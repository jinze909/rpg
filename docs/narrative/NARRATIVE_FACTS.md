# 《归来》叙事事实登记表 v0.2

“归来”为工作标题。本表列出剧情需要“记住”的事实，供任务分解和后续实现参考。**它不是已实现的变量或 API，也不规定存储方式。** 事实名只是建议，实现侧可以改名、合并或拆分，但“记住什么、在哪里写入、在哪里被读到、缺失时怎么办”要保持一致。

职责沿用项目基线：ORK 管任务与存档，Makinom 管交互与剧情，Unity 管表现。具体落到哪一层，由玩法侧对照 gameplay baseline 判断。

## 二、写入与读取的原则

- 事实先记“发生过什么”，再记“怎么评价”。同一事实可以被多个章节读到，不同章节的反应可以不一样。
- 关键事实至少有两个来源。比如“桥是被自己人断的”，来源有缆口、桥夫记录、钟声信号、陆钧自承、韩峤的底稿，玩家错过任何一个，其余仍能指向它。
- 每个“被读到”的位置，都要有“缺失时”的默认值。默认值不能让人物说出和之前矛盾的话。
- 夜点名三遍不应先记缺席待查，正式战死需核验与签报；M00 纪念日不重新判人死亡。点名名单（roll_call_list）由事实生成，包括谁愿意到场应声、谁没来、谁说“下次”；不得替小七强制起名。

## 三、软锁与一致性检查清单

- 沈砾、祁雀、韩峤、伊蕾、陆钧任何一位离开、翻脸或死亡（战斗死亡须区别于叙事选择）后，主线都有替代路线和更高的代价。
- 渡口之夜的证据丢失、被销毁或没拿到时，M12 仍能进行，只是你的牌更少。
- 战斗失败后的重试，与叙事选择造成的后果分开。重试不改变任何事实。
- 点名与名册是叙事要求，不是玩法承诺。核验可依现有名单、本人经历及证词，不要求人人有三份完整文书；东岸家属不能伪装成晏军阵亡者。如果玩法侧评估后不做专用名册对账，同样的叙事可用对话与任务记录替代，M10 的拼写事件可由伊蕾与当事人的对话完成。听雾只提供一里内的粗略方向，不能单凭声音证明身份。
- 没有暗中流逝的真实倒计时。重大转运、夺关、封航由章节事件推进，启程前说明会关闭哪些活动。
- 赤盐营救成功是共同节点。后续选择不追溯删除已经落脚的人。
