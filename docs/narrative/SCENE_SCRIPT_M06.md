## 第一场：泵房重逢（先问吃水线，再算逃亡账）

**【画面与 2D 工业现场 THAD 演出】**
深夜。赤盐矿区深处，地下蒸汽泵房。正中央两层楼高的铸铁排水泵活塞持续上下往复（`Anim: Pump_Piston_Loop` + `SFX: Pump_LowFreq_Hum`）。
四人同步作业，绝不站桩等玩家：
- **沈砾**半截裤腿泡在铁锈污水里，踩在二层铁梯上用“监察员”重型管钳死命别住三号副阀（`Anim: Wrench_Work_Up`）；
- **小七**在梯底每两拍往返工具箱递垫片；
- **梁伯**在右下角铁皮炉前大火煎咸鱼（`VFX: Oil_Smoke`）；
- **欧林**靠在左门框锉锁芯，见你从通风道跳下来，只抬眼扫了 0.5 秒便低头继续锉锁。

**沈砾**（头都不回，反手一甩，一把沾满黑油的副扳手擦着你耳边砸在铁管上，`SFX: Metal_Clang_Loud`）：闭嘴！别喊！三号井的传音管直通上面管事房，你嗓门再大半寸，我现在就把你塞进排水渠里冲下去！

沈砾：你还敢跟我提“现在就走”？三个月前你翻墙跑了那一趟，鲁斯把三号坑的口粮停了整整一个月！

沈砾：**老张**是饿得眼花栽进碎石机旁没熬过去的，小哑巴是喝了渗水洞的苦水烂穿了肠子！现在这底下还有五百号人，最大的这台泵一停，三天之内海水倒灌，底下五百人全得变成腌肉缸！

沈砾：你瘦了。这不公平，被关在矿里挨饿的是我。……迟到三个月，你知道三个月我能修多少台泵吗？
