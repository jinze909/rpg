## 一、泵房重逢

**夜。赤盐矿区地下泵房。**
巨大的蒸汽排水泵轰鸣运转。**沈砾**正在拆一个阀——停机检修是她给下层五百人换班的掩护。**欧林**在背后修锁，装作什么也没看见。
你走到泵台边。重逢时，沈砾没有先看你，而是先看你身后的水面。

沈砾：**几个人？吃水线多深？**

- `[若走韩峤船坞（voyage_path == 韩峤船坞）]` 你：主船能装三十人，吃水六尺，外港还备了接应盐驳。
- `[若走陆钧护航（voyage_path == 陆钧护航）]` 你：两条护航船在礁外，浅水艇进港，吃水四尺半。
- `[若走祁雀商路或混合（voyage_path == 祁雀商路 / 混合）]` 你：先遣船十几个人，吃水不到四尺，外港还有接应船队。

沈砾：**……行。**

确认之后，她才转过头来看你。

沈砾：**你瘦了。这不公平，被关的是我。**

[“沈砾，我来接你了。”]
[“三个月没见，你给扳手起的名字还是那么难听。”]
[“船就在外港，我们今晚就能走。”]

沈砾（擦了把汗）：**迟到三个月。你知道三个月我能修多少台泵吗？**

## 二、泵房里的人与易达的茶

泵台下面蹲着一个十五岁上下的少年，正在往上面递工具。沈砾叫他**小七**，他叫她“师傅”，两人互相嫌对方手慢。

沈砾：把扳手递给我。

小七：哪把？

沈砾：税务官。

小七：它为什么叫税务官？

沈砾：因为你不敲它，它不理你。

小七又转头去问门边的**欧林**：

小七：这把锁几分？

欧林：三分。

小七：你上回说它五分。

欧林：上回我心情好。

小七又指了指最外层通道口那把暗锁（当年欧林被拿家人要挟着修过的那把）：那把呢？

欧林（擦锁的手停了一下）：**那把不评。**

角落里，六十出头的**梁伯**正在铁炉上偷偷煎盐鱼，被沈砾骂火太大。

梁伯：这是梁伯的规矩，鱼要大火！

这时，管事**易达**提着灯来巡查。他看了一眼泵房里多出来的你，什么也没说，只在本子上划了一道，放下一包茶：

易达：**鲁斯先生问沈工好。**

（易达转身走了。那包茶放在铁台上，**沈砾没碰，也没扔**。）

## 三、送信与她藏着的事

[操作：把外港带来的八封信一封封送到收信人手里]

（收到“我把门槛修好了”的女木匠**陶霁**当场拆开读了两遍；收到一整页账目的矿工把信揣进怀里没拆；还有一位矿工看了一眼信皮，把信还给你，说他想想怎么回。）

送信回来时，**欧林**（或老矿工）低声告诉了你实情：
沈砾在赤盐替鲁斯修了十年的升降机和排水泵，产量翻了一倍，口粮跟产量挂钩，这让三百人吃饱了，也让鲁斯的账更漂亮——矿工里有人叫她“救命的”，有人叫她“鲁斯的工程师”。**而三个月前你逃走后的那个月，鲁斯扣了半数口粮报复，有两位老矿工（其中一位叫老张）没熬过去。** 她自己没说，打算自己扛。

> **【玩家抉择：得知此事后的反应（写入 `shen_relation`，三种做法都不被惩罚）】**
> - `[直接问她那两位老矿工的事]`
>   沈砾（手里的扳手停住）：**我顶得住。——是，顶得住和该顶是两回事，别拿那种眼神看我。**
> - `[先帮她把眼前的阀修完再说]`
>   你拿起“税务官”替她稳住螺母，等把阀门装好试通，她靠在铁壳上，低声跟你说了老张走那天的情形。
> - `[等她自己开口]`
