# 同行闲聊与地点评论 v1.2

“归来”为工作标题。本文是可改的写作基线，不代表已实现内容。对白用来定语气，不是最终文本。能否实现、触发方式和界面由玩法侧对照 gameplay baseline 评估。依据见 [NARRATIVE_GUIDE.md](NARRATIVE_GUIDE.md) 第八节。

## 为什么要有

故事靠一群人撑起来：沈砾、祁雀、欧林、小七、阿鸢、陶霁。如果他们只在过场里说话，玩家在航行、赶路、做名册案的几十个小时里，身边就是一片安静。闲聊让他们先是彼此相处的人，之后才是和你的关系。

## 规则

1. 闲聊是同伴之间的对话，不围着玩家转。
2. 三类触发：地点（走到某个点）、组合（谁在队里）、状态（章节推进或案子结果）。
3. 每段两到四句，少分支。地点评论只有一句。
4. 同一对人物的闲聊分先后：第一次、第二次，后面建立在前面之上。
5. 被战斗或过场打断之后，回到安全处可以重播。
6. 带条件的闲聊要标明条件，缺条件时不出现，不用别的话顶替。

## 航行与雾

**出海第一晚｜祁雀与阿鸢**
阿鸢：这一句我昨天唱的是“潮”，今天想改成“朝”。
祁雀：你再改一遍，船工分成我也改一遍。

**雾里｜祁雀**
祁雀：雾里别喊我的名字。我的名字贵，喊一次收一次钱。

**雾里｜沈砾与欧林**
沈砾：雾真大。
欧林：别叫我的名字。
沈砾：我叫的是“老欧”。
欧林：那也是名字。

**听雾练习之后｜阿鸢**
阿鸢：它学得像，可它不会拖腔。真人总会多拖半拍，像舍不得说完。

**夜航｜祁雀**
祁雀：全船静音。现在谁的肚子叫，下一顿谁洗碗。

## 沈砾与祁雀（改船）

**第一次**
沈砾：再塞一张床，我能把这条船改成八层。
祁雀：改成八层我就要收你升降机的钱。

**M09 之后｜仅沈砾仍参与时**
祁雀：床位表我划了十八条线。你每多一个名字，我就得删一碗饭。
沈砾：那我少吃。
祁雀：你少吃，我的船工就看着你吃。你觉得谁更难受？

## 沈砾与欧林

**M08 之后**
欧林：你又替谁答应了什么？
沈砾：没有。
欧林：那你手里怎么多了一张单子。
沈砾：……顺手接的。

**修东西时**

沈砾：我给它五分。

## 小七

**第一次出海**
小七：海没有边，天也没有边，那它们是怎么分开的？

**与沈砾**
沈砾：把扳手递给我。
小七：哪把？
沈砾：税务官。
小七：它为什么叫税务官？
