# ST-02 · 河面上两盏头灯（地区与长期人物故事之二）

> **【双岸四站航线图锚点：① 西岸家乡·城郊白苇平原芦汀义庄】**  
> *（羊皮纸海图徐徐展开，朱砂航迹越过迷雾停驻于当前航站，铜罗盘咔哒定格）*

> **核心母题**：名字属于谁（造物署名权与生死默契的托付）。
> **开放窗口**：M02—M04 芦汀镇河灯节前夜；M10—M15 回访与河灯节回响。
> **核心升级（告别传话跑腿，同船画“三八线”夜航 + NPC 撞碎选项框主动互救）**：
> 1. 砍掉在东头船坊和西头漆铺之间来回跑腿传话的冗长流程——镇公所为了省钱，直接把**谢枝的旧船头（左舷带歪脖子鹭鸟木雕）**和**闻笙的新灯架（右舷全暗榫夜光生漆）**强行拼在同一艘试验渡船上，甲板正中用白粉笔画了一条“三八线”，让你当公证人同船夜航！
> 2. 实装**【左右双色头灯切换夜航机制】**；
> 3. 在旧闸钢缆崩断瞬间，弹出常规二选一选项框，但**倒计时走半截，谢枝和闻笙直接伸手把 UI 选项框“撞碎/推开”，不等玩家批准就扑向对方半区互救**！
> **出场人物**：你、谢枝（留乡女船匠）、闻笙（归乡漆匠）、镇公所承办人。
> **写入事实**：`st02_state`（`1`=独立争冠分包, `2`=联名投标且无损过旧闸, `3`=联名投标但重损卸架）。

## 第一场：同一批灯骨与画了“三八线”的拼装试验船

**【画面与器物细节打架（Show, Don't Tell）】**
傍晚。芦汀镇渡口码头。三年一度的河灯节就在明晚。
女船匠**谢枝**和归乡漆匠**闻笙**今天下午先后花了双倍价钱雇你去买断同一批楠竹灯骨。等你把灯骨送到码头时，镇公所承办人干脆拍板了一个缺德又省钱的法子：把两人的作品拼在同一条试验船上同船试航！

你走上试验船甲板，眼前的环境细节让人忍俊不禁：
- 甲板正中央被白粉笔死死画了一条**“三八线”**（`Prop: Chalk_Line_Center`）；
- **左半边（谢枝侧）**：全是老凿痕、桐油味，船头立着那只她保留了六年、**脖子歪成四十五度的木雕鹭鸟**（那是闻笙当年学艺时画歪的第一笔，鸟嘴上还被闻笙恶作剧挂了个小漆桶）；
- **右半边（闻笙侧）**：光滑得苍蝇站上去都劈叉，连一颗外露铁钉都没有，水线以下全靠**谢枝独创的燕尾双扣暗榫**咬合，船顶架着三层夜光生漆灯架。

## 第二场：双色头灯夜航与互揭老底

**【核心可玩机制：左右双头灯偏振切换夜航】**
夜幕降临，河面起雾。你掌舵驶入遍布旧沉船与新水闸暗桩的芦汀水道，可随时按键切换点亮船头的两盏大灯：
- **点亮左灯（谢枝的黄光桐油聚光灯）**：光束顺着歪鹭鸟嘴尖斜射向水下，照亮枯水期隐藏的水下石桩阴影；
- **点亮右灯（闻笙的青光荧光散射灯）**：青光洒在河面，令水面上涂过同种生漆的暗流漩涡浮标显形。

你开左灯时间一长，右边的闻笙就开始阴阳怪气；开右灯时间一长，左边的谢枝就拿烟锅敲船帮：

闻笙（用两根手指嫌弃地捏起鹭鸟嘴上的麻绳，往右半边退了半步）：谢大匠人，您这只鹭鸟的脖子要是再往左歪三寸，整条船的风水都得跟着它落枕。合同上要是签您的名字，夜里坐船的客商还以为芦汀镇的木匠全害了斜眼病。

谢枝（头都不抬，用烟锅敲了敲脚下严丝合缝的暗榫甲板，`SFX: Pipe_Knock_Wood`）：总比某人的暗榫强。外头看着光溜得像剥壳鸡蛋，真撞上三号旧闸底下的铁牛桩，连个受力的明楔子都找不着——到时候整船人抱着你那十层大漆的招牌喂鱼，鱼都嫌漆味儿呛嗓子！

## 第三场：旧闸撞船——撞碎选项框的本能互救！

**【画面与打破“玩家中心主义”的高光演出】**
试验船驶入镇中心的**窄石旧闸口**。
突然，上游一艘失控的观景游船顺水斜冲过来！闻笙船顶那座三层展翅灯架猛地卡进旧闸石梁缝里，湍急的旋涡将船体狠狠往石壁上甩去（`Shake Camera: 0.5s`）！

此时，屏幕中央按传统 RPG 惯例弹出紧急二选一抉择框：
> `【紧急抉择（关键回合抉择）】`
> - `[保谢枝的左舷船体，砍断闻笙的灯架]`
> - `[保闻笙的右舷灯架，硬抗水下铁牛桩]`

**然而，倒计时条才走到一半，根本不等你按键——**
屏幕上的两个小人突然同时跨过甲板中间那条白粉笔“三八线”，**直接伸手把屏幕上的 UI 选项框撞得粉碎（`UI VFX: ChoiceBox_Shatter`）**！

**谢枝**一把拽住想去拔铁钎的你的后领往舵位上一塞，自己反手扑向右舷，用肩膀死死顶住闻笙那座怕水的生漆灯箱主梁；
与此同时，向来把作品看得比命还重的**闻笙**，已经半截身子探出左舷，顺着那只歪鹭鸟鼻尖指的方向，一脚踹进船底的燕尾暗榫泄力槽！

谢枝（青筋暴起，顶着冷水冲闻笙吼，`Portrait: 谢枝_Roar`）：看什么看！三寸半的燕尾暗扣是你自己埋的，我手糙摸不准销子——**这部分得让他来！**

闻笙（满手泥水，“咔哒”一声拔出暗销卸掉顶层装饰减重，顺势把青光铜提灯卡在歪鹭鸟的脖弯里，恰好照亮最后一道逃生窄闸，喘着粗气笑骂，`Portrait: 闻笙_Mud_Laugh`）：早知道你这歪脖子鸟是给三号闸测斜角留的准星……抓稳舵！顺着她那只丑鸟的嘴尖冲出去——**这部分得让她来！**

> **【玩家操作：掌舵冲闸】**
> 玩家顺着歪鹭鸟脖弯里青光提灯照亮的准星，对准暗榫受力点一篙发力（或卸架冲出），两条船并排冲出旧闸浅滩！

## 第四场：投标取舍、回访与 M15 点名回响

**【画面与抉择】**
两条船靠上浅滩，岸上围满了评审和镇民，散开的发光灯片引得孩子们追着河岸欢呼。

> **【玩家协助确认投标方案（写入 `st02_state`）】**
> - `[决定 A · 促成联合投标：主灯舟并排署两人的名字，收益与维修责任白纸黑字写清（st02_state = 2/3）]`
> - `[决定 B · 一人拿渡灯主合同，另一人拿专项船体/漆饰分包合同：各自独立挂牌，互为搭档（st02_state = 1）]`

- **日常回访（一致对外）**：
你后来回访芦汀镇时，一个贪小便宜的镇绅带着摔坏的灯笼上门，笑嘻嘻地说：“你们俩既然都搭伙了，那修船送修灯，这活儿算免费赠的吧？
  ”
谢枝和闻笙对视一眼，**人生第一次站在同一边，异口同声把门一关：“想得美！
  船工钱三钱，漆工钱三钱，少一文不接！”**
- **M15 点名回响**：
  M15 石碑点名前后，新一季河灯顺流漂过临潮外海。河面上最亮的那两盏大头灯，歪脖子鹭鸟木雕的脖弯里稳稳挂着闻笙的夜光生漆提灯，底座上刻着他们的名字。

### 【同伴在场抢白（欧林开盘赌越界 + 祁雀抽两成庄家水钱）】
- **欧林**（靠在桅杆边，指着甲板正中那道白粉笔“三八线”，抛起五枚瑟兰铁子）：“左边那个老船匠脾气急，右边那个女漆匠步子碎。我押五枚铁子，不出三分钟，姓谢的左脚必定踩过粉笔线。”
- **祁雀**（啪地打开折扇，把算盘往桶上一架）：“开盘口怎么能少了我？小七、沈砾，买定离手！本船长坐庄，赢家扣两成场地茶水钱！”

### 【RPG 船舰核心改造解锁：谢枝闻笙『歪脖子鹭鸟·双色偏振生漆渡灯』】
- 谢枝与闻笙入驻雀行号甲板工坊！解锁船首核心模块**【歪脖子鹭鸟·双色偏振渡灯】**（穿透一切浓雾与水下暗桩，战斗开场赋予敌方全体【青光致盲】）与**【夜光青生漆武器涂装（攻击必中）】**。
